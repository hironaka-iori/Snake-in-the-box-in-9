# Q9 换基搜索独立复核

目标是选择九个 GF(2) 线性无关的非零原始差向量作为轴，使所有强制点及指定数量的新增点恰好诱导一条开放路径。

## 已复现并修正的边界错误

从 `q9_gap_generations/prior191.words` 零基第 0 行取前 189 步，保留全部 190 个点，求 191 步。原见证仍有同端连续两步 79→77→69。最初的非增广 `general` 穷尽奇偶形式却无结果，形式 511 返回 CLOSED，曾检查到一组完整基。原 `find.cpp` 的末端延长每侧最多贪心补一个点。主线的 `general_fixed` 修正了这一情形；`augment` 在相同实例也能恢复真 191。`endpoint_regression.json` 记录原词、三条实际程序输出。

非增广搜索首先要求所有强制点本身在给定基下诱导一条连通路径。修正后可穷举两个端点上的延长。需要联结多个强制片段的题设，哪怕只补一个点，都应使用 `augment` 的第五个参数。`general_checked` 等旧二进制和重新编译的版本需要区分。

## 独立穷举

`exhaustive.cpp` 始终在原始点坐标工作，直接从 511 个非零差向量选出 9 个，绕过搜索奇偶线性形式及逆变换。设 S 是 n 个强制点的集合，h 为补点数。这些点在任何合法结果中诱导一片线性森林，连通分量数在 1 到 h+1 之间。因此所选轴在 S 内诱导的边总数位于 [n−1−h, n−1]。各轴支持的边互不重叠，边数可以相加。

若存在强制点 x 和三条不同候选轴 a,b,c，使 x+a、x+b、x+c 都在 S，其中任何选完的基都不可能同时包含这三轴。程序预先以原始坐标计算所有轴对以及会使它们失败的第三轴集合，只枚举不含此类三元组的九轴集合。在叶子处用完整 XOR 闭包核验秩为九。h=1、2 时枚举补点的无序组合，并在直接生成的原坐标图上穿过路径以验证连通。一般代码只支持 h=0、1、2。它没有搜索节点数量或冲突预算。

`make_inputs.py` 生成原始窗口、131 条 191 母体及阳性输入。1042 条 190 输入从相邻的 `q9_gap_generations/prior190.words` 逐次异或生成。位置索引始于零。`positive.pts` 的 24 个集合由真实 191 见证经可逆线性变换后去除两个点并打乱而得；去除模式轮换为同端两点、相邻内部两点、分离内部两点。`twoholes.pts` 从真实 192 步近路的首 260 条各删去两个随机位置，目标仍为 192。

## 独立 SAT 与森林核验

`independent.py` 在原始点标签上使用 MiniCard。指定一种奇偶形式，直接约束全局选九轴、每个强制点的诱导度及全局度数缺额。正模型逐次检查秩和所有补点。此试验限每例 40,000 个冲突，超限单列。完整基枚举的结论来自上面的无预算程序。

`forest_sat.py` 则固定基，针对 h=1–5，在全部 512 个原坐标点上选出恰好 h 个额外点，强制入选节点度数为 1 或 2，再逐个阻断不连通或环状模型。`supplied_forest.cpp` 直接驱动原 `forest.hpp`。每种孔数测试 7 个真 191 删除点之后的阳性，另测试 7 个将其中一个强制点替换后的样本；每例均将两个实际结果比较，对找回的路径检查全部 18,336 对点。数据保存在 `forest_sat.jsonl`。

## 复算

在本目录编译 `c++ -std=c++20 -O3 exhaustive.cpp -o exhaustive`，每次使用 `./exhaustive h < inputs.pts`。例如 `./exhaustive 1 < allbank.pts`。汇总程序 `python3 -B summary.py` 验证日志行数、阳性基秩和全对邻接，也逐母体比对主、独立两套搜索留下的满秩基数。`summary.json` 为最终数字。SAT 输出及枚举日志均为计算复核，未生成形式证书。
