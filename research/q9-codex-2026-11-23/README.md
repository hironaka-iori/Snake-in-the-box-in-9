# 从八维构造九维长蛇

本目录汇集本聊天的九维下界构造与 221 边排除实验。长度按边数计算。当前独立复算的下界是 **191 边、192 点**。目前没有找到 192 边开放蛇，也没有证明九维上界为 220。

## 两层只跨一次

将 $Q_9$ 写成两个 $Q_8$ 面。对两个八维蛇做坐标置换、异或平移和必要的反向，使选定端点投影相同。设两个面的八位点集是 $A,B$。两层之间的立方体边一一对应于 $A\cap B$，所以单次跨层拼接有效，当且仅当交集恰为对齐端点。长度为 $a+1+b$。

[显式见证](q9_explicit_q8_96_plus_94.json) 给出 $96+1+94=191$ 边，覆盖全部 18,336 对顶点。它属于已发表的 191 边等价类。公开的 192 边见证是闭合圈。参考[八维穷举](https://doi.org/10.1007/s00373-014-1423-3)和[九维记录论文](https://arxiv.org/html/2607.15270v3)。

| 目标 | 两臂的可行长度拆法 | 冻结母库内的实测 |
| --- | --- | --- |
| 192 | 98+93、97+94、96+95 | 已验证到 191，192 仍待构造 |
| 195 | 98+96、97+97 | 226,114,560 种相对放置，至少 10 条弦 |
| 196 | 98+97 | 4,193,280 种相对放置，至少 14 条弦 |

表中放置允许取向和坐标置换，包含对称重复。结果只覆盖冻结母库。详见 [Q8 到 Q9 的实验记录](Q8_TO_Q9_SIX_HOUR_RESULTS.md)。

## 多次跨层与局部重拼

- **以片段为单位拼接。** 单层可以放数条互不相邻的诱导路径。跨层投影的重合位置必须恰好等于设计的端口，并使各分量连成一条路径。两条外臂共 $F$ 点，加上 $m$ 边的对面中段和两条跨层边，合计 $m+(F-2)+2=m+F$ 边。实测 81 种 99 点双臂与 93 边中段最少仍有 5 条弦。放开对面选点后，对这 81 种外臂及另 17 种 100 点外臂，386 个选定端口情形都取得至多 191 的整数证书。范围限定在固定外臂、两次跨层。
- **扩大母库。** 通过四段重拼制造冻结目录以外的八维母蛇，并从高维长蛇取八维森林，优先保留投影重叠少、端口兼容的片段。切片所得的多个分量仍需要经端口连接及逐对验证。见[端口重拼](Q9_PORT_JOIN_RESULTS.md)和[局部提升](Q9_LOCAL_LIFTS_AND_EXCHANGES.md)。
- **修剪和重长。** 允许删除种子顶点并在两端或中段引入新顶点，同时允许重排路径。单弦 192 边行走适合当作种子。对特定 260 个候选的有限搜索排除了四次以内的等量顶点替换。16 个 189 边种子的另一组替换实验也未找到 192。见[种子增长](q9_seed_growth_results.md)和[重接](Q9_RECONNECTION_SEARCH.md)。
- **验证成功候选。** 检查顶点数、互异性、位宽和全部顶点对。连续点汉明距离为 1，所有其他点对距离至少为 2。用冻结目录统计或求解器预算探索时，保留原范围与 UNKNOWN 状态。

python3 -B verify_q9_record_facet_profile.py
