# 十维蛇的动态折叠构造

12 条输入均是 379 边的十维诱导路径。动作序列与本地记录归档 record_snakes.csv 中的全部十维条目逐条一致。先前的固定投影作用于整个源序列。这次允许在任意一个连续的源时间区间更改投影，并在区间结束时恢复。区间的两端通过平移对齐，保证保留的九维步始终从前一顶点出发。

|方式|区间内的变换|已检查的等效边界模板数|最长九维蛇|190 边无向类|
|---|---|---:|---:|---:|
|收缩一条轴|原先隐藏 h，区间内改为隐藏 j，原来的 h 接管 j 的目标轴|3,919,664|190|2|
|合并两条轴|源轴 h 原先解释为 j，在区间内改为 k，保留每一步|9,861,408|190|4|

当一段源序列没有受影响轴的转移时，把折叠边界放在该段内任何位置都会得到完全相同的动作序列。程序穷举能改变序列的区间边界，并扫描每次输出的全部连续起止窗口。滑动窗口每走一步更新起点，略过所有与新点重复或与新点形成非连续邻接的旧点。两个系列合并得到 4 个互不同构的 190 边类；它们都在参考归档的 1,042 个 190 边类中，且均未包含在 131 个已知 191 边类的单端截短集合中。

阳性从一条已知九维 191 边蛇构造，把第 95 步以后的一条轴替换成新的第十轴。新路径在十维中通过逐对检查，每一条轴均至少出现两次。任何固定删轴最多保留 189 步。通过一次内部换轴，程序恢复了 191 边真路径。这个人为阳性用于检查动态折叠能力。外部种子上的结果限定于上述两个构造族，不能给出九维全局上界。

在本目录复算：

```sh
clang++ -std=c++20 -O3 fold.cpp -o /tmp/q9-dynamic-fold
/tmp/q9-dynamic-fold 191 0 1 < control.steps
/tmp/q9-dynamic-fold 192 4 12 all190 < external_q10.steps
/tmp/q9-dynamic-fold 192 5 12 all190 < external_q10.steps
python3 verify.py
python3 compare.py
```

verify.py 在每份日志上依据截面切换时刻、原输入行和结束时刻，独立重建每条更新记录，并检查顶点范围、互异及全部点对的邻接。compare.py 检查全部 190 边规范类、公开库及 191 截短库的匹配。可把原始 ZIP 路径作为参数传入 compare.py，再次核对输入种子与归档。统计保存在 verified_summary.json 和 comparison.json。
