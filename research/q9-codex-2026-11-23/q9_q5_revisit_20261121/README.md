# Q4 × Q5 revisiting layer search

The 131 canonical inputs are the 191-edge words in q9_gap_generations/prior191.words. For each input, prepare.py ranks the 126 choices of four axes by use count, then retains choices giving 20–25 visits to Q5 fibres. This produced 127 labelled templates. Their Q4 order includes repeated visits. The whole-fibre method frees 3, 4, 5, 6, or 8 chosen Q5 fibres and preserves exactly the original points in the other fibres. Inside the released fibres every vertex and every vertical contact is free. A connected induced-path SAT encoding can therefore change visit counts, visit order, ports, and the order in which any retained pieces occur. It requests at least 193 vertices. The first pass uses MiniCard with 1500 conflicts per system. CaDiCaL rechecks all unresolved cases with a 4000-conflict limit. Positive controls explicitly reject the original layer order even up to reversal. Cold controls force just one new placed vertex. Partial controls also retain every second vertex, sorted by label, of the alternate target inside the released region.

The stochastic code starts from each original 191-edge witness, working directly with Q5 paths and Q4 labels. It mutates one Q5 visit, the common port and both adjacent visits, an XOR displacement of a contiguous Q4 subword, a Q5 coordinate transposition on an arc, and excursions that split or merge visits. Duplicate points and chords carry penalties. Accepted alternative high-scoring paths and near misses are checked by direct point comparisons. Two runs propose 9000 and 36000 steps per template. Full-fibre SAT supplements the stochastic search. For each saved near miss, a final pass releases every layer containing a chord endpoint, plus every set of zero, one or two other layers. Two independent SAT encodings handle the first pass and its unresolved remainder. Each SAT UNSAT status is a solver result for its specified region. No proof traces were saved.

From the workspace root run `python3 -B q9_q5_revisit_20261121/audit.py` to reproduce summary.json from the stable logs with Python's standard library. prepare.py, payload.py, mix.cpp, run.py, repair.py and repair_deep.py are the generators. The SAT code uses python-sat; mix.cpp uses C++20. The listed limits describe sampled searches.
