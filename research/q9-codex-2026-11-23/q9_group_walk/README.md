# 九维开路实验

目标是可验证的 192 边或更长的诱导开路。长度按边数，顶点用 0–511 表示。验证时要求顶点互异，任意两点的汉明距离为 1 当且仅当它们在路径中连续。

## 三组坐标

把九个坐标分成三个无序三元组，共 9! / ((3!)³ 3!) = 280 种分法。只指定每一步翻转哪一组中的一个坐标。组访问计数相同的时间点共享同一组三比特。给定该组奇偶性，三比特可由四个对径点对之一唯一确定。一次组内移动必须改用另一种颜色，对应恰好翻转一位。

repair.cpp 在初始赋值周围分支，每次改变一次组访问的颜色，同时更新该访问涉及的所有九维路径位置。对当前冲突端点，只有两端组访问索引不同的组能改正其距离；互不相交的冲突支持给出还要修改的最少访问数。EXHAUSTED 仅针对该初始赋值、分组、投影步序和修改数。LIMIT 表示仍未判定。alternate.cpp 在保留实际候选顶点序列的前提下更换坐标分组，允许后续修复改变原分组下的投影。

colors.py 独立编码完整的三组颜色约束。两端在所有组内奇偶性都相同时，要避免三组颜色同时相同。只有一组奇偶性不同时，要避免该组颜色不同而另外两组颜色都相同。若至少两组奇偶性不同，两点汉明距离至少为 2。ordered_colors.py 还要求每组的新颜色依次首次出现，消去颜色重命名。逐渐解除用作提示的固定颜色后，无假设的 UNSAT 才计作该投影步序不可行；预算用尽记 LIMIT。small_check.py 与独立短路径穷举对照，check_bounded.cpp 对照独立的有限修改枚举。

## 跨来源片段和内部弦

seam.cpp 对一条有缺陷的轨迹切除一段，尝试在一臂末端任意补步，然后检查另一臂的所有坐标置换。cross.cpp 将来自不同窗口的九维长片段接合，使用与接缝相距各个汉明距离的可用点数剪枝。hybrid.cpp 还允许出现少量弦，要求两端各五个顶点无弦，并编号记录实际发生冲突的顶点。缺陷数大于零的序列不能作下界见证。

interior.py 对这些内部有弦的候选尝试全部 280 种分组。half_repair.py 固定一个非零线性奇偶函数的一侧已有的顶点；其他点可在整个 Q9 自由选取，顺序与端点也自由。一个候选有 511×2 个这样的固定点集，可能存在等价子问题。使用已有的完整度数约束与连通性切割模型。求解器 UNKNOWN 不构成排除。

## 复查

在工作区运行 python3 -B q9_group_walk/audit.py 可更新 verified.json。文件保存各批次实得计数、阳性见证核查、两条内部弦的位置及候选完整顶点序列。输入快照在 seam_rows.in，使用的已知种子在 known.words。审计同时把两次构造得到的 192 顶点圈逐一旋转、反向、重命名轴后比较。

tiny checks: 使用带 PySAT 的 Python 运行 q9_group_walk/small_check.py；以 C++20 编译并运行 q9_group_walk/check_bounded.cpp。cross 的 DONE 行依次记录有方向的片段配对次数、候选接缝位置数、通过距离层筛选的位置数及坐标置换搜索节点数。它们是不同计量单位。
