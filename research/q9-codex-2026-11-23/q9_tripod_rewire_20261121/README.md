# Q9 三臂树的断开与多点重接

从 `q9_facet_occupancy_search_20261121` 的三份最终状态日志中找出 397 个 193 顶点的连通诱导树。逐树核验三顶点度为 1，189 个顶点度为 2，一个顶点度为 3。把分叉顶点平移至 0，再对三臂排列及坐标轴重命名取规范词，得到 217 个带几何信息的不同树类。`arms.words` 和 `provenance.json` 保存完整输入及对应的原始状态。筛出的原始记录为 warm 199、blend 193、cold 5。217 类中有 172 类的最短臂只有一边，其余 45 类的最短臂为 4 至 46 边。

**未找到 192 边路径。** 实际恢复的最长路径为 191 边。五次三段双桥搜索合计得到 83 个不同的 191 边路径同构类，均与既有 131 类目录中的条目匹配。整个构造无需固定 Q8 donor，也无手动固定的保色交换半径。

## 构造与覆盖

单桥搜索有两种形式。可以在一支臂靠近分叉处删除至少一个顶点，令其与另外两臂形成的主干断开，再独立裁切、翻转两个片段并连接任选的两个端点。也可以先完全舍弃一条短臂，再在主干内部删除一段并重接。双桥搜索直接删除分叉顶点，将三个独立臂分别从两端裁切、翻转，选择中间片段和端点方向，再从 Q9 的 512 个顶点中 DFS 两条桥。完成拼接后再从两端延长。桥点和延长点可以使用原树以外的任意顶点。移动一整臂的两次试验只接纳三片段互不相交、互不相邻的初始摆放。

| 运行 | 处理的片段配置 | 产生的不同规范中段 | 最长路径（边） |
|---|---:|---:|---:|
| 断去一臂再重接，预算 7 | 623,308 | 2,459 | 191 |
| 断去一臂再重接，预算 16 | 1,382,686 | 32,947 | 191 |
| 完全舍弃短臂，再重接主干缺口 | 716,000 | 126,018 | 191 |
| 三段双桥，六端最多裁去 16 点 | 2,030,751 | 4,300 | 191 |
| 三段双桥，六端最多裁去 32 点 | 6,271,491 | 209,500 | 191 |
| 三段双桥，六端最多裁去 52 点 | 4,368,087 | 11,479,292 | 191 |
| 一段绕端点交换两坐标后双桥重接 | 84,628 | 66,201 | 191 |
| 一段整体平移两个坐标后双桥重接 | 7,797 | 34,307 | 191 |

各运行从全部 217 个树类生成配置。除单桥预算 7 对所规定剪裁分配逐项遍历，其他运行按固定随机种子抽样。大释放运行 `tri52.log` 记录了 4,801 次双桥节点预算截断和 62 次延长预算截断，每次预算均为 100,000 节点；其余表中运行没有触及节点预算。桥点个数也有上限，详见命令。跨运行的中段可能重叠。结果不提供局部重接族或任意 Q9 路径的全局上界。早期未完成的 `fork7.log` 没有计入结果；替代的完整运行见 `f7.log`。

## 见证核验

`audit.py` 根据原始掩码重建三臂树，按日志重建片段、旋转或平移、两条桥及完整的 191 边路径，对输出顶点逐对计算 Hamming 距离，并检查原树以外的顶点数。五次双桥搜索的 318 条保存见证全部含两座非空桥。对于整体平移，51 条记录中有 45 条的两座桥各自都使用了原树以外的顶点，其中一个已知 191 边路径在该固定坐标系中包含 165 个原树以外的顶点。该数字使用原摆放而非最优等距对齐。

独立的双臂算法对全部见证提取出的 215 个不同中段分别枚举左右两臂，并测试所有长度可能改进的相容组合。每个中段均能补至 191 边，全部中段中的最高值也是 191 边。`audit.json`、`independent_tips.log` 和各运行的 `*.long` 供复核。
