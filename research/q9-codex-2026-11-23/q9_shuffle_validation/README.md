# Q9 三步、四步局部乱排的模型复核与 195 / 196 边搜索

原模型是相邻目录 q9_shuffle_blocks/search.py。实测版本的 SHA-256 见 audit.json。本目录保存对照源代码、输入选择、逐例结果和成功恢复的路径。

## 原模型的独立对照

用顶点DFS从原点列出每条真实低维诱导路径。对给定的成对坐标分组，把每条路径各块内的组号多重集作为物理真值表。再对每个测试输入调用原 solve，逐项对比可行性；对 FOUND 同时核实实际维数、每个顶点对的邻接关系以及逐块多重集。

- Q3 的长度 0–7、Q5 的长度 0–6：对每种由1–4组成的完整分块序列，穷尽每块的组号多重集。14,740 个模板全部一致。
- 另完整枚举 Q5 物理路径至无路可走。最长13边，从固定原点出发有960条有向13边路径。对长度13、14各选20个局部模板环境，每个环境含一个3步和一个4步自由窗，穷尽150种窗口组号多重集。6,000 次结果全部一致。
- 上述共20,740次，3,334可行、17,406不可行。它们检验的是所列低维模板。
- Q9 用24个已知191边实例。8个保持原词，16个在自由窗内部打乱后，输入本身经几何核验已失效。原模型对24个实例均返回191边真路径，顶点对与块条件均已独立复核。control191_3129.jsonl 同时保存了原词索引、受扰源词和见证。

## 目标搜索

| 条件 | 195边 | 196边 |
|---|---:|---:|
| 原模型，给定不均匀窗口，窗外组号时序保留 | 3,400个模板均返回 UNSAT | 3,400个模板均返回 UNSAT |
| 实际坐标仅在3/4步窗口中重排，允许求解器自行选择全部窗口 | 320个源词均返回 UNSAT | 320个源词均返回 UNSAT |

原模型每个测试划分四对坐标、一个单坐标，可在同一对内重新选择实际轴。每个目标长度的1,600个模板来自 monotone_near.words，另外1,800个来自候选池的优先原词。每个配置只有3–10个互不重叠的3/4步窗，其余位置均为单步块。选择窗口时优先覆盖几何冲突的顶点。在最初限额下3个模板未决，各用25万冲突预算复跑后均关闭。retry.jsonl 给出相应行号。这里的结果是模板级求解器记录；没有给6,800次原模型计算逐份生成证明。对前一批每个目标的1,600组指定窗，还用实际轴逐块排列的独立算法搜索过，均无见证。

anywhere.py 表示更严格的物理规则。窗口内重排源词中同一批实际坐标，允许任意多个互不重叠的3步或4步窗口，其余每一步保持原坐标。模型枚举各起点所有非恒等局部排列，要求所取窗口不能占用同一步；每个时刻选一个可能顶点，相距至少两步时禁止重合和Q9邻接。每个原词的一次求解覆盖所有这些窗位。候选池按归档评分排序取前320个；这些归档评分与实际重算的坏顶点对数可能不同。真实坏对分布见 audit.json。

直接枚举分段和真实轴排列的另一程序对1,893个小维输入与 anywhere.py 完全一致。任选窗模型也恢复了全部24条Q9阳性。195和196各在320个样本中抽取一例，额外生成 CNF 和 DRAT，用 drat-trim 独立验证；压缩证据为 physical195.*.gz、physical196.*.gz。640个目标结果均有逐行原词和来源记录。以上计算没有找到195或196边诱导路径，有限源词及其指定的变换范围仍是这一结论的适用范围。

另在同一物理模型中允许至多2或3条弦，同时仍要求顶点互异，尝试得到新种子。此项不是零弦求解，未决记录保存在 near195.jsonl 与 near196.jsonl。

## 重放

以下命令从本目录运行。几何与清单审计只用Python标准库，其余脚本使用PySAT的CaDiCaL 1.9.5。

    python3 audit.py
    python3 small.py
    python3 deep.py
    python3 check_any.py
    python3 runs.py control 191 24 3129 50000
    python3 runs.py target 195 1600 6324 18000
    python3 runs.py target 196 1600 6325 18000
    python3 extra.py 195 7486
    python3 extra.py 196 7487
    python3 retry.py
    python3 anywhere.py 195 320 60000
    python3 anywhere.py 196 320 60000

运行 replay_sample.py 需可执行的 drat-trim，本机所用路径已写入该文件。
