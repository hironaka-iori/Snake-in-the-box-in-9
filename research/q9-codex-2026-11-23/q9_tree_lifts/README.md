# 八维母路径的固定双步升维

目标是构造 192 边或更长的九维超立方体诱导路径。这里记录一类构造的搜索边界。母路径来自上级目录的 q8_catalogue_96_98.words，包含 726 条 96 边、26 条 97 边、1 条 98 边路径。summarize.py 已逐条核对顶点互异、相邻步长和所有非连续点对。

## 固定双步映射

给八个输入方向分别指派九维中两个不同坐标。沿母路径走一步，在九维中先后翻转这两个坐标。偶数步处的点称为锚点。给定锚点集合后，我们放宽到任意锚点顺序，并允许自由选择中间的奇点。

若一个奇点在两个连续锚点之间，诱导性要求它在所有保留锚点中恰有两个邻点。96、97、98 边母路径在满秩映射下分别有 97、98、99 个不同锚点，连成一条路分别至少需要 96、97、98 个可用奇点。对目录中每组长度及全部满秩映射取最大值，分别只有 91、81、76。

计算中把每个坐标对视作九个坐标之间的一条边。八个二进制向量线性独立，当且仅当这些边构成树。只对九维坐标重命名取等价类，保持八个输入标签，得到 531,441 棵树。实际检查 400,175,073 个母路径与树的组合。check_trees.cpp 通过另一套 Prüfer 序列算法重建整个树集合，并直接按九维邻接关系抽验 997,945 个计数。check_maxima.cpp 重新计算了 753 行各自的最大值见证。

## 允许替换锚点

对这批固定映射的每个像，任一长 192 至 196 边的九维诱导路径最多包含其中 93 个不同映射点。这个结论只约束与这批像的重合度。整体平移及九维坐标重命名保留同一结论。

证明所用的必要条件如下。若保留 r=94 个同奇偶性的旧点，目标路径中同奇偶性的点最多 99 个，于是还有至多 a=5 个新点可用。从该奇偶类的出现顺序中去掉新点，旧点分为至多 a+1 段。因此至少需要 r-a-1 个在保留集合中恰有两个邻点的连接奇点。把这种奇点连接的两个旧点看作一条边，所得图的连通分量数至多 a+1。若一个旧点有 d 个可用连接奇点，其端点缺额为 max(0,2-d)，所有旧点的缺额和至多 2a+2。这些条件均按最有利于拼成长路的情况计数。若实际保留更多旧点，任取其中 94 个仍须满足条件。

remove.cpp 对满秩情形枚举。按当前可用奇点总数以及剩余可移除锚点最多能增加的可用奇点数剪枝。通过初筛的母路径与树组合有 5,145,872 个，进一步检查 5,899,319 个候选子集，满足全部必要条件的为零。所有 753 行齐全。check_rem.cpp 用直接枚举九维邻接和全部子集的参考程序对照 220 个小例，含 213 个阳性和 7 个阴性。

秩不超过 6 的像至多有 64 个点。秩为 7 时核有唯一非零元 s，相差 s 的母点两两合并。仅 61 个母路径与核向量的组合仍能留下至少 94 个不同点。去掉核关系中一个方向后，七条独立坐标边构成森林。从全体树删除指定标签，再按各坐标的入射标签集合取标准代表，得到 57,611 个森林。核关系唯一确定删除方向的坐标向量，只接受重量为 2 的向量。dependent.cpp 实测 560,895 个符合条件的母路径、核、几何映射组合，20,442 个经过初筛，最终通过数为零。

## 复算

在上级目录运行 python3 q9_tree_lifts/summarize.py 可核验日志行覆盖和目录内分段、可变搭配搜索已输出的路径。verified.json 是一次核验快照。满秩日志为 up196_keep94_*.log，秩七日志为 dependent94.log。tree_check.log、subset_check.log、maxima_check.log 分别记载独立对照结果。以上穷举结论来自本地 C++ 计算；目前没有对应的 Lean 内核审计。

blocks.cpp 允许不同分段更换字典，每段内的方向映射仍可扩张成一棵树。它用有限宽度的束搜索生成具体路径。flexible.cpp 在每个双步中保留母方向，另一个坐标可随步改变。两者的搜索深度只描述其实际输出。每个输出的 BEST 行同时包含母路径前缀和九维顶点名单；复算脚本检查全部顶点对和相应升维约束。
