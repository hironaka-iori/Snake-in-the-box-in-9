# 真实 Q9 档案与 Q8 母段的双步扩展

所有转向从零开始编号。指定 Q8 母词第 j 步为 a，则 Q9 第 2j 和 2j+1 步中须出现物理轴映射 F(a)。同一条母词的 F 为全局单射。另一转向及顺序可随 j 改变。

## 精确匹配范围

- 档案含 131 条真实 191 边 Q9 路径。Q8 库含 726 条 96 边、26 条 97 边、1 条 98 边记录。包括长记录裁取的每一个连续 96 边窗口，两种方向合计 1,562 个有序母词。
- align.cpp 在任意 Q9 连续转向对中逐对二选一，将保留的词按坐标初现顺序规范化，与全部母段的前缀树匹配。最长为 24 对，即 48 条真实 Q9 边。131 条档案各自最优为 19 对的 91 条、20 对的 4 条、21 对的 34 条、24 对的 2 条。
- independent_bound.cpp 使用另一种算法验证上界。对长度 25 的 8,776 个不同 Q8 规范词和 18,602 个档案起点逐个取每个 Q8 轴允许的物理轴集合的交集。163,251,152 个组合中有 102 个的所有轴域均非空，轴间互异匹配排除全部 102 个。
- 放开目录限制时，真实 191 转向中每对选一步，另要求所得保留词本身是至多 8 轴的无弦路径。最长为 61 对。free_mother.cpp 逐步追踪禁用顶点。独立的 free_bound.cpp 对 80,172 个“档案、起点、省略轴”组合分别搜索 62 对，279,321,627 个结点无解。匹配上下界都只针对这 131 条真实档案的连续片段。

## 192 边构造尝试

- 以真实匹配段为固定中心，左右成对生长，524 次产生的最长有效 Q9 路径为 130 边，维持一个 Q8 母词的连续 65 步约束。
- 取 50 个中心种子，分别向左端或右端补全，每侧 900 次。分别有 686 次和 716 次到达指定一端。join.cpp 在同一母词的成对半段间枚举中间接缝或拆出 1 至 23 对作为待填桥，共 117,000 次半段组合与 24,255,435 个平移放置。带间隙的摆放均出现两半之间的交叠或邻接，直接无间隙拼接至少有 97 对冲突。
- coupled.cpp 从真实 191 母体枚举插入单轴后的 192 转向，保留缺陷不超过 2 的 1,124 行。随机 400,000 组全长母词对齐通过指派问题拟合物理轴，样本最高匹配 58/96 位。120 个全长初值再改变辅助翻转；2,922,377 个评估移动仍未产生 192 边见证。
- 262 次去掉真实匹配段两端后再生长的对照全部达到目标，260 次回到不同的合法词。另从长的已核验构造中删去 2–4 对连续转向，用 join.cpp 同一桥接 DFS、枚举相对平移补回，150/150 成功，最长 130 边，26 条返回不同的有效转向字。所有对应母段约束均逐步核验。

## 回放

在本目录运行。audit.py 单独核验原始 Q8 与 Q9 几何、已保存的每个锚段、逐步母词关系、双向扩展和对接阳性。witnesses.json 保存最长档案匹配、任意母段匹配以及最长实构造的转向字。完整 192 搜索属于有预算的试验。

```sh
c++ -O3 -std=c++20 independent_bound.cpp -o independent_bound
./independent_bound
c++ -O3 -std=c++20 free_bound.cpp -o free_bound
./free_bound
python3 -B audit.py
```
