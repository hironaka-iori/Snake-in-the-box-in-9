# 树编码后移动同色点

目标是含 97 个偶点、96 个奇点的 192 边诱导开路。通过翻转九维坐标的某一位，可以把两端同为奇色的路径换为此种端点颜色。每个选中的奇点须恰有两个选中的偶邻点。选中的偶点须有一个或两个选中的奇邻点，恰有两个偶点度数为一。连通后这些条件足以得到诱导开路。程序从满足这些局部度数条件的模型提取端点所在分量。若还有圈分量，就添加一条要求连接两个分量的割并继续求解。

对于同一权二掩码 m，256 个偶点分为 128 对 {v,v XOR m}。可以让每个原先只有一个占点的配对独立换侧。混合方向实验另外选一组两两不交的不同方向配对。自由增加模式从 96 个偶点开始，全图任一配对允许多占一个，其他配对保留各自点数。全部奇点的占用由求解器重新选择。

## 192 边搜索

7,470 次有限子问题包括树编码、公开 191 边路径的半集与旋转近解的半集。6,433 次返回 UNSAT，1,037 次达到冲突限额，未获得 192 边见证。其中，高连接数的 75 个树编码用于 1,700 次实验；896 个旋转近解半集用于 1,100 次。数字为试次数，其中可有重复几何模型。单个 SAT 返回状态不构成全体路径的上界。逐批计数在 verified.json 的 grouped 字段。名称为 q9mixedlocal、treemixedlocal 的早期批次实际使用同一掩码的局部配对，多方向的局部批次名称含 variedlocal。

## 实际树构造及对照

直接从一条有 77 个顶点的真实 Q8 母段出发，按一棵九点树上的八条边嵌入，然后替换 25 个偶点并重选奇点，得到一条 152 边九维诱导开路。verified.json 保存母段词、树的边掩码、移出与移入点、完整九维点序列。audit.py 独立复核树连通、母段诱导性、所有交换和所有点对。

从这条 152 边见证继续逐级增加偶点的结果另存 growth_verified.json。每次自由增加一个偶点，另可同时交换多个配对。growth_check.py 独立逐步复核每个偶点的变化和全部九维顶点对。与公开 191 边路径有关的确证恢复属于阳性对照，与这条 Q8 树来源的增长链分开记录。

对 18 个刻意交换 2–6 对偶点的 190 边真蛇，允许多个交换时全部恢复 190 边；在完全相同的配对中仅允许至多一个交换时，18 个实例全部返回 UNSAT。另 18 个先删去一个偶点、再交换 2–6 对的阳性实例也全部恢复 190 边。独立 C++ Hamilton 图程序还枚举了 24 个小模型的全部 5,032 个偶点集合，比对所得 12 个阳性、12 个阴性逐项与 SAT 相同。

## 核查

纯 Python 可验证现有见证。重新运行 SAT 需要 python-sat，重新运行图交叉检查需要 C++20。

```sh
python3 -B q9_tree_mobile/audit.py
python3 -B q9_tree_mobile/growth_check.py
c++ -O3 -std=c++20 search_q9_fixed_parity.cpp -o q9_tree_mobile/graph_solver
python -B q9_tree_mobile/crosscheck.py
```

## 解除配对限制的区域搜索

除了成对交换，regions.py 允许指定区域内的偶点完全重新分配，并可在区域外增加至多一个偶点。以相同长度的旧偶点集为基准，模型要求至少移走两个旧点，奇点仍可在全图任选。15 个先移除一个区外偶点、再在区域内错放 2–5 个偶点的阳性全部恢复真实的 190 边。

从真实 191 边路径的 96 个同色点出发，另做 750 次目标 192 的区域搜索，其中 473 次返回 UNSAT，277 次达到冲突限额。合并前述 7,470 次，目标 192 的有限试次共 8,220 次，6,906 次返回 UNSAT，1,314 次限额，均未产生见证。

树来源的具体增长从 152 边经 1,680 个配对增补试次到达 170 边，所得实例中保留了 40 条新见证。之后的区域重排从一条 170 边路径的偶点集合移出 36、430，加入 39、300、423；重新选择全图的奇点后得到 172 边。这一步的 173 个顶点均不同，全部 14,878 对通过检查。各阶段的父路径、完整顶点序列和复算记录分别在 growth_verified.json 与 region_verified.json。

```sh
python3 -B q9_tree_mobile/region_audit.py
```

从这条 172 边路径继续试了 380 次区域重排，返回状态为 {'UNSAT': 169, 'BUDGET': 211}。
