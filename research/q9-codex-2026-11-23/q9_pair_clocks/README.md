# 本地九维方向重选实验

长度以边数计。有效路径必须位于 0–511，顶点互不重复，并且恰好相邻的两个时间位置对应汉明距离 1。audit.py 从顶点重新逐对检验对照和任何返回的目标解。日志里的 UNKNOWN 表示预算用尽，只有给出并通过检查的路径才计为下界见证。

## 九维 191 边母路径的系统插入

母路径来自 q9_explicit_q8_96_plus_94.json。固定八个轴分为四个无序对，第九个轴单列。保留母路径每一步所属的组，允许它在该组内重新选择实际方向。再插入一步，插入位置及所属组任意。共有 945 种分组、5 个插入方向组、192 个位置。在一个组里交换两个名字是一种立方体等距，所以新增步可以取组中指定的一轴。

给定一对坐标及其局部步数奇偶性，两位之异或已知，只需一个自由位。插入动作把切口之后的顶点统一平移一个单位方向；切口处在未平移和平移后各访问一次。用单调的布尔变量表示切口位置。对任意非连续时间点，如果至少两个组的奇偶性不同，则其汉明距离至少为 2；其余情况在同奇偶的坐标对内要求至少一对坐标相差两位。

4,725 个“分组及插入方向组”由 full_donor.py 搜索；首轮的 409 个未决实例继续用 incremental.py 按切口区间细分。覆盖核对见 audit.json。全部实例均由本地 SAT 求解器返回 UNSAT。这一记录覆盖指定母路径及指定变换，不包含其他九维路径或 Lean 内核审计。24 个 191 边删步、扰动、再恢复对照全部找回合法 191 边路径。

## 七条两弦 192 步近解

对每一条尝试全部 945 种配对，并允许全部 192 步重选对内坐标，保持原步的组序。6,615 个实例在 search.py 和补查 buckets.py 中全部得到 UNSAT。首次有 526 个实例耗尽预算，较宽预算及另一编码在 retry_two.jsonl 中返回确定结果。

## 拓宽构造

two_insertions.py 同时求解两个任意补步的位置。ordered_end.py 可将八维母路径每个翻转映成九维的两步，各段内能自由换序与重选组内坐标。其中 195 边按 97 个双步段加一个末端处理。fit_mothers.cpp 按八维步序与九维近解的两步段求最佳方向匹配，再交给同一个几何求解器。domains.cpp 在选中的冲突区可让一步取全部九个方向。以上拓宽试验包含限额与抽样；不能给出九维全局上界。各组原始状态见相应 JSONL 日志。

## 两条弦及外端的后续核查

进一步只要求消去原先两条弦中的一条，允许指定的另一条仍在，但禁止所有新增弦。在 7 个种子、945 种配对和两种保留选择组成的 13,230 个实例中，初次求解有 85 个未决，提高预算后全部返回 UNSAT。这里保持时间上的组标签不变；移动多余邻接的位置或改变组序仍是开放的路线。

另外逐条验证 131 条档案母路径的 262 个端点，向任意一个方向多走一步均会重复顶点或引入弦。故任何合法 192 边路径的 191 边前缀和后缀都不属于这 131 个对称类。novel_search.py 在搜索时直接屏蔽已知类，并检测新类的外端；控制试验分别留出一个类，28 次均恢复合法 191 边结果。

也可以寻找一条两端分别可延长的 190 边路径。因为 190 为偶数，两端同色，外端的两个新点也同色、彼此没有边；它们也不可能重合，否则各自就会接触原路径的另一端。因此各端能分别延长就足以得到 192 边。biends.py 在成对改轴的同时给两个外端各自开放所有九个方向；both_controls.jsonl 保留小规模对照和独立核验过的长路径。
