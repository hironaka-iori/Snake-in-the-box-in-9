# 同一双内部弦母路径的局部变形重组

目标是 193 个互异 Q9 顶点组成的 192 边诱导路径。q9_three_axis.in 的 5,062 行中有 1,559 条几何不同的合格输入，每条恰有两个非连续点对相邻，四个弦端指标均位于路径内部。两条弦可以共享端点。几何类按整体平移、坐标重命名和路径反向规范化。

## 搜索

1. build.py 对同一近路径剪开若干窗口，在保留的外部顶点间枚举多条局部桥。每条桥贡献候选顶点。sat.py 对并集顶点做自由占点，强制其中的公共骨架、两色点数、两个端点和选点诱导度，遇到单独的圈便添加排圈子句。输出的连通路径可以重排原片段。100 个双内部弦输入、每个 6 个窗口组合和两种多数颜色共 1,200 个分支。1,198 个报告 UNSAT，2 个达到冲突预算。
2. isos.cpp 在一个弦端附近取时间区间，生成保持两个边界点的坐标置换，或交换边界后反向。只保留 193 顶点均互异、至少一条原弦消失的完整变形。程序在 1,559 个输入上累计生成 394,569 个各输入内几何去重的合格变形。每组保留的一部分共 157,208 个，audit.py 独立逐一重建并核对弦数和全部增删顶点。
3. iso_solve.py 在每个母体的 5 种变形顶点并集和两种多数颜色上搜索 192 边，每个模式有指定必选顶点。15,590 个分支在首轮和 retry.py 的 8 次复测后全部由本地 MiniCard 报告 UNSAT。未导出 SAT 证明证书。另在 160 个母体的全部保留变形并集上解除全部必选顶点，320 个颜色分支在 1,200 冲突预算内均无结论。
4. mix.cpp 另扫描 8,099,137 对同源变形，其中 5,045,365 对物理增删集合两两互斥。无重叠的时间区间给出 39 条逐点核验的单弦 192 步，17 个规范类均在近路径输入库中。
5. all_variants.py 在全部保留变形并集上放松原母体两弦附近的公共骨架，先求 191 边。598 个母体给出有效 191 边路径，493 个返回解使用的新增顶点无法由任何单一变形提供。共 72 个规范类，都在已知 131 条档案中。offspring.py 从这些真实解去掉一端的 0 至 14 步后，再生长出 5,783 个至多双弦的 193 点变形（按母体计数），与原母体变形的顶点再重组。3,588 个颜色分支中 2,071 个报告 UNSAT，1,517 个达到预算，未发现真实 192 边。

## 阳性与复核

从 50 条有效 191 边档案中，各将两处分离的方形转角换到对角点，得到有两条内部弦的受损 192 顶点输入。联合桥顶点池 50/50 修复。49 个输入的每一个单桥池各自都报告 UNSAT。另用完整等距变形的三种选择模式，150/150 个 191 边阳性通过。

实际目标母体 q9_three_axis.in 第 1486 行产生的 191 边实例在 near191a.jsonl 第 1 行。从 3 到 14，192 个互异顶点共 18,336 个无序点对。只有相邻指标的 191 对相邻。解需要原母路径以外的顶点 16 和 42，该母体保留的 125 个完整变形没有任何一个同时提供这两个点。该实例属于 131 档案的零基编号 68。完整顶点列表和出处保存在 checked_example.json。

在本目录运行 `python3 -B audit.py` 可用 Python 标准库复核保存的完整变形、所有实际阳性路径和单弦新组合。audit.json 逐文件区分 FOUND、UNSAT 和 LIMIT。所有结论限于各自指定的并集、必选点及冲突预算。
