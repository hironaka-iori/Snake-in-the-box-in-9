# 成组对调同奇偶顶点，再重建另一色路径

在 131 个已知的九维 191 边蛇类中，每条蛇的两种颜色各有 96 点。任选一色，用平移归一化为偶色集合 S。选一个重量为 2 的掩码 t，把偶点配成 {x, x⊕t}。以 c 为中心，令一对到中心的距离为 min(d(x,c),d(x⊕t,c))。将指定距离范围内的所有配偶同时对调。此操作保持点数且自逆。分别枚举了距离至多 2 和距离恰等于 3 两个范围、所有 36 个掩码，以及每个掩码模配对相同的 256 个中心。目标为用新偶点集作九维 192 边蛇的 96 个少数色顶点。

|模板|至少 3 对确实对调|度数必要条件排除|剩余模板|不同剩余集合|192 边|
|---|---:|---:|---:|---:|---:|
|半径 2|2,065,544|2,065,447|97|55|0|
|第三壳层|1,207,292|1,207,292|0|0|0|

模板可能产生相同集合。无未决案例。对 55 个剩余集合另用 Python 深搜，5,410 次递归访问得到一致结果。具体做法是把邻接恰好两个偶点的奇点压缩为偶点间的边，把仅邻接一个偶点的奇点标记为可能端点。要求一条遍历全部偶点的简单路径，首尾各须有可用奇点。与 C++ 中的边选择搜索不同，这个核查器直接按访问顺序搜索。

阳性对照成功找到 191 边路径，包括一个从原 96 个偶点中同时换出 5 个、换进另外 5 个的例子。Python 检查了真实对调的顶点集及 192 个输出顶点的全部顶点对；两个阳性均落在旧 191 类库。完整顶点列表见 control_3swaps.log。该实验排除了两种模板中的指定集合，不给出九维全局上界，也不支持对精确值的排序。
