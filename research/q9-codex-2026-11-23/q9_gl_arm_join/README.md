# 两条长臂各自线性换基、按新点集重排，再拼接

本轮最长见证为191边。输入来自七条192步两弦近解和公开131条合法191边路径。从近解取全部93–100边无弦连续窗口，从每条档案路径取相同长度、靠两头或中间的若干窗口，具体下标见 bank.py。去除坐标重命名、平移及反向等价，得到3,916种长臂。provenance.json 可逐个追溯。

## 换基后的次序

枚举可逆的秩一剪切 T(x)=x+u(v·x)，运算在GF(2)上，u、v均非零，且v·u=0。每个九维点集有511×255=130,305种参数。用变换后拉回的九个单位方向检查点集本身的诱导图，要求连通、最大度2、恰有两个度1端点，再沿图上邻接重新读出路径。第一轮共510,274,380种参数。2,309个变换打断原次序而仍成蛇，其中1,791个改变端点对。新增1,300个臂类。继续对新类施加剪切，又得到92、12、0个新类，达5,320类。

直接同时替换两条坐标基方向、检查所得方向组成独立基，新增12个臂类。再取剪切与两方向替换的联合闭包，稳定在5,332类。两种独立的候选生成程序找到相同的12类。对这5,332类又分别穷举保留其余原方向、同时替换恰好3到7个方向的情况，各阶均未触限或产生新类。选择新方向时要求相对于保留方向线性无关，并按非单位方向的无序组合归并坐标重命名。

其中62类的仿射支撑维数是8，单独补完8方向替换，仍无新类。一条连通路径的边方向张成其全部点差，在线性像中每个被用到的物理轴相互独立，故这种臂成蛇时恰使用8个物理轴。由此覆盖这62类能成蛇的全部可逆线性像。对满九维支撑臂，恰换8或9方向只做了有节点限额的样本，完整GL像仍开放。

## 拼接

每个臂的两个端点都可作为接缝。左臂固定后，右臂可自由重命名九个坐标并平移，使两臂共享端点，或以一条边连接。右臂的每个前缀都可作为实际使用的臂。程序用转移词前缀树共享等价坐标分配，提前排除和左臂相交或额外相邻的分支。全部5,332²=28,430,224个有序类对共检查2,241,300,326个坐标分配前缀，最高191边。第一轮以后只补做至少有一侧是新增类的组合。

所有达到185边的共享端点或单边桥拼接再次搜索，62,137次放置归并成3,828种路径。每种路径在两外端合计至多自由添加7步，仍最高191边。另从新臂中按固定余数抽278类作左臂，尝试2–4步自由接缝桥再接任一右臂，未达到185边。best.json 的191边样本均属于公开131类。所存191边样本不能代表每一条成功放置。

## 复核

16组对照从不同的真实191边路径出发，分别剪切并重排两侧，让得到的两条臂本身仍然是蛇。直接对齐这些改变后的臂，在原有拼接类型和全部相对坐标置换下合计39,191,040次试验全部失败。对每个臂单独逆变换并重求图上的排列后，16组全部恢复可拼接性。inverse_controls.json 给出了32个逐臂核查的逆变换。

audit.py 从原始来源及记录的线性映射重建各类路径，从臂、接缝和相对坐标映射重建存档的拼接，并逐对检查顶点互异与诱导性。small.py 独立枚举全部11种至少2边的Q4臂、复算秩一剪切像，并对60个小拼接库逐个比较显式置换。check_gl4.py 对这11种臂直接枚举各自支撑维的整个一般线性群，与换基器得到的像类一致。verified.json 汇集各范围的节点、触限与结果。这里的有限排除是本地程序的计算结果。
