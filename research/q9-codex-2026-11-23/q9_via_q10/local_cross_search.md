# 本地九维路径搜索

## 两段八维路径之间还剩多少连接空间

从本地八维母库截出 2,488 种有向 95 边片段。固定一臂后，另一臂可在九维立方体中独立重命名全部坐标并任意平移。枚举两臂顶点互异、没有跨臂额外邻接（仅允许待连接的两端直接相邻）的所有放置。逐个平移和同时处理 512 个平移的位集实现分别算得 360 种。对每种放置删去已占用非端点的闭邻域，保留两个连接端，独立的广度优先搜索在全部 360 例中都无法连通。

允许近解后，再任选各臂的一个端点，并试探两端之间汉明距离最短的桥。单调桥每个不同的坐标只翻转一次。动态规划对每个坐标子集累积向两臂引入的额外邻接数，禁止重复顶点。全部 1,440 个端点组合均检验。最优桥有并列时抽取至多八条，按坐标置换、平移和反向去重。得到 445 种 192–197 步近解。在输出的 79 条 192 步近解中，7 条只有两条额外邻接。105 条 195 步近解中最少七条额外邻接，101 条 196 步近解中最少八条。完整顶点与额外邻接的下标见 checked_near_walks.json。此局部最小数不约束其余九维构造。

## 放开路径形状

从不同母路径的共有步序确定一组相对坐标对齐，然后自由选择桥和两个外端。进一步可只固定每隔一个时间步的顶点。设固定顶点集合为 S。如果连续两个固定顶点的某个公共邻点在 S 中恰有它们两个邻居，就能用其作为中间顶点。按此条件可在一次搜索中改变整条路径的另一种奇偶颜色。搜索器还尝试增加连接处和外端的固定顶点，再检查全部约束。外端搜索的损坏对照恢复了全部 131 条已知 191 边长度。独立的 Python 验证见 audit_free_tips.py 与 free_tips_audit.json。

随后将交叉拼接产生的候选用于时间顺序变形、固定一个奇偶色后开放全部排列，以及多个冲突区同时释放的局部回溯。new_order_192.pts、new_order_195.pts、new_order_196.pts 分别包含 3,877、2,019、478 个相应长度的起点。这些文件允许含弦，不能直接用作下界。seven_bridges.jsonl 与 monotone_sat_*.jsonl 记录允许更换占据顶点的局部 SAT 搜索。UNKNOWN 表示在该次预算内未决。所有未获得合法路径的试验均不能给出九维全局上界。
