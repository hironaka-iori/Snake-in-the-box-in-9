# 可重新着色的188边核心与双端自由生长

在同一分组中，八个九维坐标配为四对，余下一坐标独立。核心指定每一步所属组。每次用到一对坐标时，模型可重新选择其中任一坐标。核心两端的每一步都可独立选择九个坐标中的任意一个。主目标固定188边的核心，两端各补两步。实验也覆盖不等长的两端，以及188边核心上3+4、4+4步。

## 搜索结果

| 五条Q8单跨一弦近解 | 21 | 945 | 19,845 UNSAT |
| 由两条Q8蛇的96边及94边片段拼成的合法191边路径 | 4 | 945 | 3,780 UNSAT |

每个分组的两端方向和核心内部的组内着色都交给求解器决定。四种显式191窗口与前21类互异。审计在坐标置换、平移及反向下检查等价性，前一行的原始窗口共25个。每类分组数为9种单独坐标乘以其余八坐标的105种无序配对。这个有限子域全部得到求解器 UNSAT，没有限额未知项。未生成形式化不可满足证书。

含Q8母段双臂、筛选过相对置换的双臂、已知191种子和近解的常规批次中，192边共3,361次、195边共1,316次、196边共1,261次，最终均返回UNSAT。初次冲突预算用尽的41例另以200,000冲突预算求解。每个目标至少含公开131种191类各一个独立实例。这些批次和表中完整子域有重叠，统计表示模型运行数。

## 模型与核验

每对坐标的异或值由分组步序固定，一个布尔变量描述该对第一坐标的当前值。选定的两帧在至少两组的奇偶值不同，则其汉明距离至少为2。如果至多一组不同，就要求另外至少一个坐标对的第一坐标取值不同，以排除点重合或非连续邻接。自由端各层以相对核心端点的位掩码表示，连续层必须汉明相邻，同一臂的非连续层和两臂之间的所有点均受距离约束。所有长度均以边数计。

Q3的150个实例与Q5的200个实例分别用物理轴上的逐步DFS独立判定，全部与SAT结果一致，其中有72个可满足实例。40个长阳性对照从真实191边路径上去掉两端，再随机扰乱核心的组内着色；40个输入的物理核心均已损坏，40次均重新得到191边合法路径。audit.py 对完整见证逐对核验、重建组投影，也由记录的母段、裁切、方向及轴置换重建Q8输入。另用已有逐方向域通用CNF复算12个长阴性实例，全部返回UNSAT。

目录内的 verified.json 为审计汇总，control.jsonl 和 control5.jsonl 含全部长阳性见证。solver.py 提供主模型，all_onechord.py 和 all_explicit.py 完成两个有限子域。保留的源代码、带种子的输入生成器、逐例日志和有限子域分片汇总可在本地复查。普通审计只需执行 `python3 audit.py`。求解器要求装有 PySAT 及 CaDiCaL 195 的 Python。
