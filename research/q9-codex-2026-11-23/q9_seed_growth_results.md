# 九维路径的局部构造与排除范围

从 `q8_catalogue_96_98.words` 中任选两条八维母路径，允许重复。分别放在九维立方体的两个平行八维面里，任意平移、置换坐标、删点或多次跨层。另可从整个九维立方体选至多三个外部顶点。对这个构造族，局部穷举给出的最大值为 **191 边**。

* 下界见 `q8_catalogue_lifts_verified.json` 的 `lower_certificate.vertices`。192 个不同顶点的 18,336 对汉明距离逐对验证。
* 上界见 `q8_all_192_three_seed_growth.log`。753 个母体的 283,881 个无序对共对应 2,930,196,971,520 种带标号摆放。按投影重叠的必要条件过滤后，剩余 4,188,729 种；双端搜索没有找到 193 个顶点的诱导路径。任何更长路径都包含一段恰好 193 个顶点的诱导路径。`q8_independent_prefilter_192_three.log` 单独复算了进入搜索的摆放数。该日志只验证过滤数量。
* 搜索原理：若宿主有 N 个点，目标有 193 个点，最多允许 e 个外部点，宿主最多缺 k=N+e−193 个点。取 k+1 个顶点互不相交的母路径连续段，至少有一个连续段全部保留。因为最终路径是诱导路径，这一整段必须按原顺序或反序连续出现。从它的两个端点枚举所有可接点，或选择结束一端；每个成为内部点的顶点，其余未用邻点均不能再用。原宿主中的每个三叉点及其三个邻点至少要删一处，用最少删点数剪枝。对照见 `q9_seed_growth_claw_controls.log`（12,000 个小立方体实例逐一对比直接穷举）与 `q9_seed_growth_planted.log`（需要 0 至 9 个外部点的九维阳性实例）。
* 五维层拼接另见 `q9_q5_relaxed16.log`。若逐层访问不同的五维面，每层只走一条连续路径，只保留相继两层之间的接触约束，15 层最多 192 个顶点，16 层最多 204 个顶点。因此用这种方式构造 192 边需要访问全部 16 层。该松弛的 204 个顶点不能直接当作九维路径。真实四层成方形时最多 50 个顶点，见 `q7_four_q5_exact.log`。

以上是本地可复跑的组合计算。它未给任意九维诱导路径设置全局上界。另一路完整三外点回放的进度保存在 `q8_clustered_hosts_plus_three_0.log` 与 `q8_clustered_hosts_plus_three_1.log`；只有 `DONE` 才算相应计算完成。

复算双端搜索可使用以下命令。四外点版本可在编译时再加 `-DQ9_CLEAN_INTERVALS` 以启用奇偶性和不触及三叉点的区段剪枝。

```sh
c++ -O3 -std=c++20 -march=native -DQ9_SEED_GROWTH search_q8_clustered_hosts.cpp -o /tmp/q9-grow
/tmp/q9-grow 192 0 1 3 < q8_registered_donor_clusters.txt
python3 -B verify_q9_seed_checkpoint.py
```

**更大的外部预算。** 在完整的 753 条八维目录上，允许至多四个任意外部点时也排除了 195 边，允许至多五个时排除了 196 边。若只看九个在完全使用宿主内部即可达 191 边的原始阳性摆放，则逐级穷举表明，引入至多七个任意外部点仍达不到 192 边，见 `q9_positive_seven.log`。这些九个摆放并不代表所有摆放。

## 不限制外部顶点

对同一目录的 283,881 个无序母路径对，允许任意多个外部顶点后，保留至少 190 个宿主顶点的分支已全部排除，见 `q8_all_retain190_unbounded.log`。因此任何至少 192 边的九维诱导路径，在每种摆放中至多保留 189 个宿主顶点。192、195、196 边各自至少需要 4、7、8 个外部顶点，即边数加一再减去 189。保留门槛版在 12,000 个小立方体实例上与独立穷举一致。

复算时在上述编译命令中增加 `-DQ9_RETAINED_HOST`，运行参数 `192 0 1 3` 对应保留门槛 190。
