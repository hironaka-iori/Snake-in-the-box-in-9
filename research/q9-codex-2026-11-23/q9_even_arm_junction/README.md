# 两条 96 边臂的同色锚点拼接

每条 96 边臂仅保留沿路径取出的 49 个偶数时刻顶点。把两臂共用的接缝平移到零，固定第一臂坐标，对第二臂允许九个坐标的任意置换。全图每个奇点都可重新选择。若保留臂内锚点的顺序，欲得到 192 边，须走完 49 + 49 − 1 = 97 个不同的同色顶点，并为连续锚点各取一个连接奇点。

## 原顺序全库

| 来源 | 去坐标等价的有向同色锚点序列数 |
|---|---:|
| 131 条公开 191 边档案的所有连续 96 边窗口，两个方向 | 3,860 |
| 十维母蛇投影的 96 边记录 | 892 |
| 十一维投影 | 2,670 |
| 十二维投影 | 4,151 |
| 十三维投影 | 7,368 |
| 去除来源间重叠后的并集 | 17,793 |

相对于接缝的方向保留。锚点序列的步差均为权二掩码，按其九个坐标随步数出现的二值列规范化。两序列规范化相同，当且仅当它们只差一个坐标置换。高维投影集合之间有 1,148 项重叠，公开档案与高维投影没有共同的规范序列。

含自配对的无序臂对为 17,793 × 17,794 / 2 = 158,304,321。全部配对与每组全部相对坐标置换均已覆盖，未发现 192 边。前缀树搜索访问 3,394,380,842 个可行前缀状态，尝试了 12,688,865,201 次双步映射。三个分片均没有左臂触及单臂上限。

固定锚点时，两个相邻锚点在九维恰有两个共同奇邻点。某个奇点可用，当且仅当整个已选偶点集里只有这两个锚点邻接它。若一段已有唯一可用奇点，则将其邻接的其他偶点列为后续禁点。若现有两种选项，一个新的不同偶点最多破坏其中一种，因为两个奇点的共同偶邻点恰好是原来的两个锚点。这说明 parity State 的禁点更新在保持原锚点次序时是精确的。各段最终选择的奇点不会重合，一个可用奇点只对应一对锚点。

搜索中另检验了缩短第二臂后再加单步端点的路径。独立核验到 52 类 191 边路径，均在已知档案中。这些路径的第二臂未走满 96 边。verified.json 保存完整见证、两臂编号、实际保留的双步数和坐标映射。

## 对照和额外重排

32 个阳性从 190 边真蛇剪成 96 与 94 边的臂，在保持各臂独立无弦的条件下，主动替换 1–9 个奇点。固定这些奇点时，独立枚举 32 × 9! = 11,612,160 个相对置换，零解。释放奇点后 32 次均恢复真实 190 边。另一套以共享接缝为端点的双 Hamilton 图构造也在相同对照上 32/32 成功。

对 1,200 对选择的完整 96 边臂，还逐一枚举 435,456,000 个相对置换，同时放开两臂内部的所有锚点次序。仅 336,884 个摆放在接缝以外没有重合，均未通过完整拼接。此批的 Hamilton 搜索没有未决项。基于前缀树的同类补充实验另有三个无截断的代表左臂。100 个左臂的限额批次中，99 个触及限额，不作为穷尽结果。

## 复核

独立的 state_check.cpp 遍历原次序与增补次序的全部 35,281 条臂，在正反方向的 3,457,538 个前缀逐一检查所有 36 种双步。直接枚举每条旧边的两个候选奇点并重算邻接数，共比较 124,471,368 次，全部与增量 State 一致。audit.py 独立重建输出的偶点、九轴置换与候选奇点，并核对所有顶点对。

```sh
D=q9_even_arm_junction
python3 -B "$D/audit.py"
c++ -O3 -std=c++20 "$D/junction.cpp" -o "$D/junction"
"$D/junction" "$D/arms.txt" "$D/order.txt" 0 17793 1000000000 1
```

## 增补的合法臂内次序

对 17,793 个原臂在其原有 49 个同色点上枚举以接缝为端点的 Hamilton 遍历，每臂最多 64 条遍历或 100,000 个搜索节点。共记录 975,826 次遍历，14,131 个臂达到其中一种限额。17,530 个臂找到不同次序，独立验证所有增补次序使用原有同一批偶点，且每一步都能选到合法奇点。规范化去重后有 17,488 个新增序列。

合并库有 35,281 个有向臂，共 622,392,121 个无序臂对。原库已检查 158,304,321 对，新增 464,087,800 对亦全部检查，所有相对坐标置换均纳入，没有一次臂匹配触及节点上限，仍无完整 192 边拼接。新增匹配实际访问 2,488,174,485 个可行前缀。此处穷尽的是这 35,281 种已生成的次序，其余臂内遍历仍可能产生不同结果。
