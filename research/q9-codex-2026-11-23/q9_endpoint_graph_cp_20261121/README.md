# 端点改道未决分支的有限域求解

**原有 119 个未决颜色分支现已全部排除 192 边。** 每个分支有独立 CNF 和 DRAT 证书。第三方检查器 drat-trim 对 119 份证明逐一返回 VERIFIED。随后从原始记录重建了全部 119 份 CNF，并与已检查文件逐字节比较；证书哈希也再次核对。见 `branch_manifest.jsonl`、`proofs_checked.jsonl`、`check_final.log` 和 `audit.json`。

原始文件为 `../q9_uncovered_endpoint_relocation.jsonl`，涉及 `comparison191.words` 中 22 条路径。半径 2 的 704 个颜色分支原已判 UNSAT；半径 3 的 704 个分支原有 585 个 UNSAT、119 个 UNKNOWN。本轮独立证明对应最后这 119 个。两个半径合计 1,408 个分支均已关闭；其他 1,289 个沿用原始求解记录。

## 搜索范围

给定原路径、选定的原端点 e 和邻点 y，阻挡点为原路径上与 y 相邻且不等于 e 的顶点。原路径中距任一阻挡点至多三个坐标的顶点允许自由改动，e 始终保留。y 必须占用，所有阻挡点必须删除，其余原路径顶点必须保留。y 在输出路径中可以是内部点。目标为 193 个不同顶点，按端点所在的多数颜色分别测试 97 与 96 个顶点。这些结论适用于具有上述固定占用与删除条件的精确 192 边目标。

## 独立模型

`run.py` 使用本机 OR-Tools 9.15.6755，针对残余顶点产生占用布尔变量，邻接点对另设变量等于两端占用的逻辑与。选中顶点的度数加其端点指示量恰等于 2，端点总数与两色占用数精确固定。常规模式检测连通分量并切除无端点环，也少量测试了显式单回路模型与 Q3 局部上界。该 CP-SAT 路线合计单独解出 14 个原 UNKNOWN。最小度消元在局部度因子涉及的自由占用变量图上给出的宽度上界为 80–166；此统计未计全局计数因子。传播后自由占用变量数为 132–228。

`certify.py` 从原路径和原改道条件独立构造 CNF。它直接对每个已占顶点的邻居占用数与可能的端点位施加条件度约束，用 totalizer 实现全局两色数量和端点数量。四个顶点构成一个正方形时禁止全部选中。此编码允许路径之外另有环，因此它的 UNSAT 足以排除真实路径。119 个分支全部在此松弛上获得 UNSAT，无需增加长环切。119 份证明的求解器为 CaDiCaL 1.9.5。最后两个为档案 108 和 109，均取 side 1、y=83、多数色 1，分别使用 376,630 和 398,881 次冲突。它们的宽度排序为 96 和 111（从 0 起）。

## 阳性与反例检查

档案 63 和 81 的 191 边对照保留原路径的未释放部分，关闭新占用点和阻挡点禁令，分别找回 191 边合法路径。更严格的阳性来自档案 82 的 side 1、y=306、多数色 1，保留原改道新点与全部禁用阻挡点，仅将目标下调为 184 边。CP-SAT 实际找回 185 顶点诱导路径，在 `exactpins184.jsonl` 的 rank 2 记录。独立检查了所有顶点对、端点、原固定点和阻挡点。该赋值在第二套 CNF 中以 185 点为目标时通过，改为 193 点时被拒绝。

## 复核

在本目录运行。CP-SAT 与 PySAT 安装在不同的本地 Python 环境；`DRAT_TRIM` 可以指定独立检查器路径。直接调用下列逐证书循环会重新执行检查，不使用以前的检查记录。

```sh
for f in rank*.cnf; do drat-trim "$f" "${f%.cnf}.drat" || exit 1; done
python_with_pysat -B audit.py
python_with_ortools -B run.py --rank
python_with_ortools -B run.py --secs 1.2
```

原始分支可按 `branch_manifest.jsonl` 的 archive、side、new_vertex、radius、majority 定位；rank 仅用于关联本目录的文件名。每个 `rankN.cnf` 与 `rankN.drat` 成对保存。全局 Q9 192 边路径是否存在仍未解决。
