# 两次跨层、两个全局端点都在下层

将两条有向八维诱导路径 A、B 从同一个 t 写起，令 x 为 B 的末点。拼出的九维点序列为 reverse(A)、256+B、x。A 和 B 仅在 t 重叠，且 x 与 A 中所有点的八维汉明距离都至少为 2，则该序列是诱导路径。其边数等于 A 与 B 的顶点数之和。最优可行见证可在 short_verified.json 的 best_path 字段核验。

## 95 边与 95 边的精确库拼接

finite_bank.py 对 2,870 个无向规范词逐对验证。1,244 类来自 q8_catalogue_96_98.words 中的 95 边连续窗口，1,626 类来自 q8_novel1626_95_20.words，两个集合不相交。short95_catalogue.cpp 对下层词的两个取向和每个上层词的两个取向，遍历第一次出现的上层坐标的全部单射，公共起点确定相对平移。同一前缀合并。枚举仅跳过无孤点的下层和已经与下层冲突的前缀。

覆盖 7,842 个下层母段、选择端点、孤点三元组，搜索 499,640,495 个前缀。7,520,840 次合法前缀命中可有重复，最长拼合 138 边，完整 95 边上桥命中 0。作为对照，short95_control.words 的真实 93 边下臂和 95 边上臂完整恢复 190 边拼接。

## 允许库外顶点的构造

从 6,518 个不同转移词中生成 124 个通过全部九维顶点对检查的起点，有 4 个达到 190 边。最佳见证的 191 个不同顶点需检查 18,145 对。四条公开 191 边路径的轴 5 给出 2、96、94 顶点层段（允许倒序），剪去短臂外端可达到本分支的 190 边。公开库的零起始索引见 short_verified.json。

| 搜索 | 实际覆盖 | 结果 |
|---|---:|---|
| 始终可行的内部区间及尾部替换 | 105,549,223 个递归节点 | 最佳 190 边 |
| 允许暂时相交的双臂替换 | 311,793,726 个递归节点 | 最佳可行 190 边 |
| 两臂尾部同时释放 | 2,234 组不同前缀，28,453,811 个节点 | 未得到目标 191 或 192 |
| 两条臂的四端同时开放，允许移动共同跨层点 | 9,687 次几何子问题，86,105,720 个节点，18,697,284 次组合核查 | 未得到目标 191 或 192 |

最后一种构造用 124 个短臂种子分别做恢复对照，124 次均返回原长度的合法见证。随机和限额搜索不提供库外全体上界。最低缺陷的 192 步候选首尾重复，去掉重复末点得到合法 192 顶点诱导圈。将其当作开路时有两条非连续相邻点对和一对重合顶点。

## 历史 96–98 边母段的低成本整数复核

指定下层 P、孤点 x 和跨层的母段端 t，另一端 u 与 x 为全局端点。设 s(v) 为偶色取 +1、奇色取 −1。上层的八维颜色差为下层颜色差减去 (s(x)+s(u))/2。上层所含全局端点数为 0。排除 192 边以上所需的最小总顶点数，在 u 与 x 同色时为 193，异色时为 194。分别有 1,653 和 1,339 个几何分支。

对应的严格整数界分别覆盖 1,410 和 1,290 项，共 2,700/2,992。本次未剪除的 292 项包括同色 243 项和异色 49 项。所有 2,992 项以 replay.cpp 重新核查，另外固定随机种子的 100 项使用独立 Python 枚举面状态重新算出相同整数。清单为 old_catalogue_manifest.jsonl。这里的部分结果不改变仓库中已记录的更一般历史排除。

## 复算

在工作区根目录可用以下命令重建母段库，运行精确拼接，复核几何、整数界和搜索见证。脚本读取相邻的历史目录，C++ 采用 C++20。

```sh
D=q9_two_cross_lower_tips_20261121
python3 -B "$D/finite_bank.py"
c++ -O3 -std=c++20 "$D/short95_catalogue.cpp" -o "$D/short95_catalogue"
"$D/short95_catalogue" "$D/short95.words" 95
"$D/short95_catalogue" "$D/short95_control.words" 93
python3 -B "$D/audit.py"
python3 -B "$D/check.py" check old_catalogue_native.jsonl old_catalogue_manifest.jsonl
```
