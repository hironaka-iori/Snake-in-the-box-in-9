# 从八维母蛇提升到九维：5,483 类母臂的单跨层枚举

固定这批八维母臂，目标为 **192、193、194、195、196 边**时，所有单跨层接法至少分别留下 **1、5、6、10、14 条弦**。同一程序找到了 **191 边、零弦**的路径。这里的“弦”指路径中两个不连续顶点仍在九维立方体中相邻。一条弦就足以使该行走不满足诱导路径条件。

| 目标边数 | 各臂长组合的最小弦数（括号内为达到该值的放置数） | 检查的放置数 |
|---:|---|---:|
| 192 | 98+93：9（5），97+94：5（35），96+95：1（5） | 28,523,980,800 |
| 193 | 98+94：9（1），97+95：6（36），96+96：5（8） | 10,562,549,760 |
| 194 | 98+95：10（9），97+96：6（8） | 987,840,000 |
| 195 | 98+96：10（2），97+97：10（2） | 136,442,880 |
| 196 | 98+97：14（2） | 4,032,000 |

表中两臂间另有一条跨层边，总计检查 40,214,845,440 个放置。最低弦数描述本表的有限母库和接法；九维最长诱导路径的精确值仍然未知。

## 证据怎么查

192 的五个最近解都有 193 个不同的顶点。第一条从低层走 95 步，在索引 95、96 的顶点 0、256 间跨层，再在高层走 96 步。从 0 编号，**唯一一条弦连接索引 0 和 179，顶点编码为 56 和 312**。两点异或为 256，恰差第九个坐标。删去索引 0 后，就得到一条 191 边诱导路径。独立的正对照另以 94+1+96 找到 191 边行走，并逐对确认零弦。[五条完整行走](q8_complete_single_cross_near_192.txt) · [191 正对照](q8_complete_single_cross_191_control.log) · [逐对验证结果](q8_single_cross_complete_verification.json)

## 搜索范围与计数

将两条有向母臂的接合端都平移到八维顶点 0。低层依次走向 0，高层从 256 出发。对其中一臂枚举全部 (8!=40,320) 个坐标排列。固定低层的坐标顺序已吸收两层共同的坐标变换。每条母臂内部都是诱导路径。两层之间只有对应顶点相邻，故额外弦数正好是两个八维占用集合在原点以外的交集大小。

母库取所有来源中连续的 93 至 98 边片段。正向与反向分别按坐标首次出现顺序重新编号，再对相同的有向词去重。独立检查每条母臂的顶点互异、相邻步长和所有非连续顶点对。来源包含 Bitterman 的 18 条历史顶点序列、393 条替换实验源记录以及高维摘录中的 162 条八维长臂。本次快照的 393 条均为搜索完成记录，计入它们所指的母臂；其中没有新增顶点序列记录。[七个输入文件、哈希与各自新增量](q8_single_cross_complete_bank.json)

| 八维臂长 | 93 | 94 | 95 | 96 | 97 | 98 | 合计 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 有向词数 | 5,970 | 3,302 | 1,200 | 442 | 50 | 2 | 10,966 |
| 合并反向后的形状数 | 2,985 | 1,651 | 600 | 221 | 25 | 1 | 5,483 |

每种长度组合只列一次，以长臂为被排列的一方。若两臂等长，保留有序的上下层配对，允许同一臂配自身。因此一行的放置数是有向词数之积乘 40,320。该数可包含在整体反向或立方体对称下等价的行走。

## 复现

完整压缩包附有输入快照、源代码、最终母库、每个长度组合的一条最优样本和日志。在解压目录运行以下命令，需要 Python 3.10 或更新版本及支持 C++20 的编译器。

```sh
python3 build_q8_single_cross_bank.py
c++ -std=c++20 -O3 search_q8_single_cross_onechord.cpp -o q8-lift
for n in 192 193 194 195 196; do
  ./q8-lift "$n" 1 "q8_complete_single_cross_near_$n.txt" q8_single_cross_complete_arms.txt > "q8_complete_single_cross_$n.log"
done
./q8-lift 191 0 control-near.txt q8_single_cross_complete_arms.txt > q8_complete_single_cross_191_control.log
python3 verify_q8_single_cross_lift.py --independent 195 196
```

Python 校验器重建每个最优样本的两条母臂，检查库成员资格，逐对验证弦数，并按有向臂数独立计算放置数。对 195、196，它还用不同的位集置换算法重新遍历全部放置，核对每种组合的最小值及重数。192–194 的完整枚举使用 C++ 程序。冻结母库 SHA-256 为 `f6936d91e1ee26e26a1e43eb21c4f8d63b81cdd51485ed8a2deb67eb022a6252`。
