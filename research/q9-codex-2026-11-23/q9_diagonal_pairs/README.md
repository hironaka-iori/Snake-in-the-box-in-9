# 九维路径的局部对角投影搜索

对于至少有三位为 1 的掩码 m，将顶点分为点对 {v, v xor m}。原立方体相邻的两个点对之间恰有两条互不相交的边。每个点对可选一个或两个顶点，移动投影的版本还可以释放原点对或启用此前空的点对。

lift.py 在固定占用点对集上求解。mobile.py 在顶点层检查度数，要求恰有两个端点，把孤立环逐次切除。参数使用负数时按至少该边数搜索，正数表示恰该边数。neutral.py 在空间靠近的路径片段周围释放点对，跳过已知库中在坐标重标与反转下相同的 191 边路径，尝试延长新得到的路径。

verified_snapshot.json 保存一次逐日志统计。每条非空路径都用独立的点对遍历复核，检查全部顶点互异，汉明距离 1 当且仅当两顶点在给定次序中连续。UNKNOWN 表示求解预算耗尽。UNSAT 限于该行使用的投影、允许替换的范围及目标长度。

阳性对照 capped_controls.jsonl 使用同一条已知 191 边路径，从一端截去两边后，保留已有点并重新搜索。在 67 个所选投影测试中，求解器都给出经验证的 191 边路径。它们可能相互等价。short_controls.jsonl 是同批对照在不限制替换数时的结果。
