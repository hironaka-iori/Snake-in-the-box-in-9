## 六个严格扩大的已证排除范围

`grow_core.py` 将原必选顶点分批改成临时假设。每批都从其余仍必选的顶点重新生成邻接域和 CNF，避免沿用依赖已释放顶点的剪枝。若求解返回 UNSAT，只保留该批假设中求解器实际使用的不可满足核。所得集合只是足以排除目标的一组条件，未验证其为最小核。随即从最终条件重建 CNF、生成 DRAT 并运行独立检查器。

## 真实重新构造

`fit.cpp` 分别把 131 条已知真实 191 边路径的有向边对齐 e、y，通过坐标置换与平移优化摆放，筛掉碰撞原阻挡点的结果。8 个分支各保留 20 条摆放（分支内各十条令 y 为内部点和端点），共 160 条，逐对验证并核对与源路径同构。其中 16 条代表允许多释放 21–44 个原固定点。保持这些额外释放不加任何其它占用限制，两色合计 32 次求解在每例 14,000 次冲突内均未决。限制从移植路径删除至多 5 或 10 个点的 64 个较小邻域，在各 9,000 次冲突内 36 个返回 UNSAT，28 个未决。16 个相应 191 边阳性全部实际恢复。

直接构造中使用同一分支下的两条不同摆放，并保留两者共有的原必选点、e、y 及原阻挡点禁令。

- 端臂拼接测试 23,845,760 个截臂组合，取每个源中长度至少 22 的前缀或反向前缀，两段长度之和在 170 到 197 之间，允许最多 18 个任意 Q9 桥点，再从两端延长。产生 97,594 次桥接完成，最高 191 边。
- 内段移植测试 68,624,628 种端部裁切和内部替换组合，在两个公共顶点之间移入第二条摆放的连续片段（可反向），然后双端延长。去重后搜索了 2,042 种“中段、必选集”组合，最高亦为 191 边。
- 两轮共实际保存并逐对核验了 74 个不同 191 边同构类，全部已在 131 类目录中。单一输出相对两条固定坐标父路径分别至少用了 6 个各自路径以外顶点的实例见 `interior.log`。
- 每个分支另选取一对摆放，额外释放 31–60 个原固定点。在其并集里独立恢复八个 191 边阳性，两色共 16 个无外点的 192 边目标均获 UNSAT。最多增加 3 或 8 个外点的 32 个目标在每例 12,000 次冲突内均未决。以上局部 UNSAT 仅六个核心排除族另生成了 DRAT 证书。

所有较大无界求解和带外点求解的 UNKNOWN 均保留。未测试的改道和全局 Q9 最长路径仍未决定。

## 复核

从本目录运行。Python 搜索需要 PySAT；几何预处理使用标准库，两个构造器需要 C++20。原始姿态、对应的档案与条件见 `placements.txt`、`branches.json`。正例、放宽后的确切点集和各自冲突预算见各个 JSONL。

```sh
python3 -B prepare.py
clang++ -std=c++20 -O3 fit.cpp -o fit
./fit > placements.txt
clang++ -std=c++20 -O3 crossover.cpp -o crossover
./crossover > crossover_final.log
clang++ -std=c++20 -O3 interior.cpp -o interior
./interior > interior.log
python_with_pysat -B grow_core.py 4 8 2 0 12 36 > grown.jsonl
python_with_pysat -B challenge.py
python_with_pysat -B union_search.py 0 2 4 8 12 36 96 111
for f in core*.cnf; do drat-trim "$f" "${f%.cnf}.drat" || exit 1; done
python_with_pysat -B audit.py
```
