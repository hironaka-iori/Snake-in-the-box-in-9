# Q9 三组坐标异源重组试验

把九个物理坐标分成三个三元组。第 k 组从真实母路径取得转向字，保留该组内部的转向顺序。若该组已走过 c[k] 步，其物理位移为 P[k][c[k]]。三个物理位移按位异或得到当前 Q9 顶点。每一步只增加一个计数，求解器可改变三个转向字的交错顺序。

## 样本与结果

- generate.py 在档案母体 A 上替换两个分离的窗口。每个窗口在另一条档案路径上取材，分别重映射坐标，且两个窗口的坐标映射不同。共保留 10,581 个 192 步输入。其中 2,610 个输入的两个窗口来自同一条 B，其余的两个窗口各来自不同的档案母体。两个窗口的组标签均发生变化。重排搜索没有返回有效 192。
- complete_tracks.py 分别索引 131 条真实 191 边路径的三个坐标投影，将来自至少两个不同母体的三条完整转向字交错。540 个 192 步输入中，404 个组标签序列无法通过在任一档案 191 的组标签中插入单步得到。此项比较覆盖 280 种三三分组、组改名及路径反向。53 个输入至少改变了所用近解模板的一条组内物理转向字。剩余输入直接借用模板的组内投影，并独立核对了其全部真实母体来源。
- retime.cpp 将一个事件移过若干组外事件。pairwindows.cpp 允许在冲突附近同时打开两个时间窗口。后者检查了 45,900 组窗口，完整遍历了 42,519 组在窗口外兼容的情形，DFS 在这些情形均未触及预算。未返回有效 192。
- freeclocks.py 将每一时刻可用的三组计数编码为 SAT。全部 540 个输入在三组计数各自偏离原进度不超过 1 时，求解器返回 494 个 UNSAT，另有 46 个在几何筛选时已无可达状态。半径 2 下 368 个输入被排除，172 个仍无结论。半径 4 抽测 48 个，6 个 UNSAT，42 个达到预算。这里只记录本地求解器报告，未导出形式化证明证书。
- seam_damage.jsonl 记录 120 个 191 边阳性输入，在两个指定边界上均受损。120 个均恢复为真正的 191 边诱导路径，覆盖 75 个已知等价类；返回解在两个切点的三组计数都改变。77 个输入的切点分属两个不同窗口，另外 43 个在同一窗口两端。seam_example.json 是可逐点核验的实例。
- 另有 100 个全投影来自其他档案母体的受损阳性输入，事件移动全部恢复。将 540 个 192 步候选分别去掉首步或末步，得到 535 条有效 191 边输出，其中 404 条的裁剪输入仍有缺陷。535 条归入原有 131 档案中的 48 类。

## 回放

在本目录运行。audit.py 只使用 Python 标准库，独立读取原母体、重做坐标重映射与原始标签比较，并逐点检查每个成功输出的全体点对。它同时汇总求解器逐行记录中的状态。

```sh
python3 -B audit.py
c++ -std=c++20 -O3 retime.cpp -o retime
./retime seam_damage.in seam_replay.paths 8 12 17 120 61934 0
```

固定随机种子的回放产生 120 个有效 191。每行依次存储输入行号、原始缺陷数、输出缺陷数和物理坐标转向字。缺陷数是重复顶点索引对数加非连续但相邻的索引对数。输出路径起点统一为零。

每个 *target*.jsonl 文件保存相应输入的来源、组划分和转向字。complete_radius1.jsonl、complete_sat2.jsonl、complete_cadical.jsonl 和 complete_sat4.jsonl 保存三个半径的逐个求解器结果。audit.json 汇总可回放数据。全域的任意重排或其他母轨迹组合仍未穷举。
