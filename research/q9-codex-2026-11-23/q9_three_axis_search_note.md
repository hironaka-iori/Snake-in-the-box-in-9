# 九维诱导路径的六维投影检验

输入文件 `q9_three_axis.in` 每行给出一串坐标编号。从顶点 0 开始，读到编号 d 就翻转第 d 位。路径长度按边数计。

## 为什么可以用四色判定

从九个坐标中选三个作为隐藏坐标，每个时刻只固定剩下六位。起点的九维奇偶性可通过整体翻转一个隐藏位归一化为偶数。因此在时刻 i，隐藏三位的奇偶性由 i 和已知六位的奇偶性确定。Q3 的八个顶点分为四对互补顶点。给定奇偶性和互补对编号，就唯一确定了三位。

- 两个时刻的六位相同时，如果隐藏奇偶性相同，必须选择不同编号以避开重复顶点。如果隐藏奇偶性不同，那么两点在 Q3 中要么互补（距离 3，编号相同），要么相邻（距离 1，编号不同）。相邻时刻必须取不同编号，其他时刻必须取相同编号。
- 六位距离为 1 时，额外的九维邻接只会在隐藏三位完全相同时出现。隐藏奇偶性相同的时刻，沿路径的边要求编号相同，其他时刻要求编号不同。
- 六位距离大于 1 时不可能产生弦。输入构造保证连续时刻的六位距离至多为 1。

合并要求相同编号的时刻后，在其余不等约束上做四色搜索。若得到解，程序重建九维顶点并逐对检查所有汉明距离。若搜索预算耗尽，单独计数。

## 可复查的输入与结果

- `q9_three_axis_verified.json` 记录 5,062 个去重候选的实际弦数和 425,208 次固定投影检查的结论。`verify_q9_three_axis_run.py` 从转移串独立核对弦数与正对照路径。
- `q9_three_axis_191.in` 保存 131 个已核验的合法 191 边输入。`search_q9_three_axis_insert.cpp` 在每个投影转移串插入一个符号（六个保留方向或停留），其后各点随之平移，再重建全部隐藏坐标。可在一段相同符号中产生相同转移串的插入位置只测试一次。
- `verify_q9_three_axis_repair.cpp` 直接枚举三位坐标，和四色法及投影改动一个顶点的搜索在 220 个小实例上比对。
- 本轮输出中的 `DONE` 表示对应输入和限定搜索方式执行完毕。`FOUND` 行附有可核查顶点，正对照的目标为 191。

## 复算命令

在当前目录运行，使用支持 C++20 的编译器。

```sh
c++ -O3 -std=c++20 search_q9_three_axis_recolor.cpp -o /tmp/q9-color-audit
/tmp/q9-color-audit 12000 0 < q9_three_axis.in
c++ -O3 -std=c++20 search_q9_three_axis_insert.cpp -o /tmp/q9-insert-audit
/tmp/q9-insert-audit 192 10000 0 1 < q9_three_axis_191.in
c++ -O3 -std=c++20 verify_q9_three_axis_repair.cpp -o /tmp/q9-repair-audit
/tmp/q9-repair-audit
```
