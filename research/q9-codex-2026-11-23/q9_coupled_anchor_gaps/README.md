# 双侧偶锚缺口的联合重建

输入是七条193顶点两弦行走，以及从先前双臂拼接日志中按坐标置换、平移和反向归并的52个191边合法类。prepare.py 验证输入每一步的汉明距离、顶点互异性和全部非连续点对。两弦输入取原路径下标为偶数的97个点作锚。191输入分别用两个下标奇偶类，各96个锚。这里「偶锚」描述双步表示，种子起点可在九维立方体任一色。

固定两锚之间所需的一条双步连接时，两锚必须相距2，有两个共同邻点。选定的连接点在已选锚集内必须恰有两个邻居。每个保留的连续锚对至少有一个这样的邻点，且不同锚对选用的连接点必然互异。由此可以在部分森林上边添加任意同色点，边排除已无可用邻点的布局。若两端再各延伸一步，两端所选异色点须分别只有一个锚邻居。候选见证最后逐对验证。

## 更宽的有界试验

另跑4,970,074个布局，涉及双缺口、三缺口、保留中段的坐标交换或平移，以及重排片段次序和方向。单个主缺口最多释放13个原锚。1,627,336次初始森林可行，总计53,139,536个搜索节点，16,297次达到节点限额，未输出192边见证。布局是各批次的计数和，可能重叠。未将其与小范围布局相加作互异覆盖声明。

在原191种子上设置191目标，双侧均须失去至少一个原锚。65次成功，归并为20类，均见于独立读取的公开131类191档案。各输出分别丢失左侧1到3个、右侧1到2个原锚。另对190边目标有114个有效输出，归为42类。

对208个阳性实例，将左右两侧各一个锚改成一个不在原锚集中的同色候选，保持所有连续锚之间的汉明距离为2。分别仅施加左侧或右侧破坏、保留干净的另一侧时，均至少有一个锚对的两个共同邻点在锚集中有额外邻居。两侧同时修复后全部得到190边路径。独立审计核实每处破坏、记录的两个错误锚均未保留，并逐对核对所有输出。另有312个使用错误奇偶性的简单对照全部通过。

在本目录执行 `sh replay.sh` 重跑主搜索、举证及审计，执行 `python3 check_seven.py` 进行额外独立复算。表中有限结论限于这些输入、缺口布局和保留顺序。audit.json 汇总日志，best191.json 保存一条双侧确实改动的合法路径。
