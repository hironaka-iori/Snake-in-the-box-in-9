# 九维蛇的条件精确值 191

取 [原始分支记录](../q9_junction_first_omission.jsonl) 首行的 75 个九维顶点。所有包含这些顶点的诱导路径，最大长度恰为 **191 条边**。还可以从这 75 个点中放开至少 13 个。对 [核验摘要](verified.json) 中列出的同一组 62 个点，仍有这个精确值。锚点只要求出现，位置与顺序均自由，其余顶点均可使用。

| 必须保留的锚点数 | 两端均偶的顶点上界分子 | 两端均奇的顶点上界分子 | 两端异色的顶点上界分子 |
| --- | ---: | ---: | ---: |
| 75 | 1,922,058 | 1,913,478 | 1,922,398 |
| 66 | 1,922,066 | 1,916,196 | 1,924,109 |
| 63 | 1,922,709 | 1,918,190 | 1,925,418 |
| 62 | 1,922,993 | 1,920,269 | 1,926,299 |

分母均为 10,000。颜色是顶点九位二进制表示中 1 的个数的奇偶性。以上每个有理数都小于 193，故路径最多有 192 个顶点、191 条边。[明示见证](../q9_parent_junctions.jsonl) 的第 1 行含全部 75 个锚点，程序逐对检查了 192 个互异顶点间所有 18,336 对的邻接关系，达到上界。本结论适用于这些指定坐标中的锚点及其立方体对称像；九维全局最优值仍未确定。

## 可复核的上界

[独立核验器](verify.py) 只用 Python 标准库，从原始锚点重新建立可选顶点。几何传播使用诱导路径的度数、端点配额和无环性。例如，必选点已有两个必选邻点时，任何其他邻点都不能入选；某可选点连接同一必选连通分量中的两个点时，取它就会形成环。用于任意长度的三类证书均未设定路径长度或两色顶点数。端点奇偶组合决定两色顶点数之差为 +1、−1 或 0。

对每个可能顶点枚举入选后的局部方向（一或两条边），并独立枚举每个三维小立方体内所有诱导线性森林。路径所选顶点及方向在两种枚举中相符。一组整数乘子分别加在顶点与小立方体的相应状态上，符号相反，对于可实现路径逐项抵消。核验器重算各枚举块的整数最大值并求和，从而得到表中各项，无需调用线性规划器。[三类整数乘子文件](unbounded_duals)

原分支树末尾的 37 个偶色端点叶也逐一完成了整数证书重放，顶点上界分子范围为 1,710,581 至 1,889,291。公共父节点多要求顶点 144，禁用顶点 26 和 508，其单份证书分子为 1,898,731。上面的 75 锚及其较小子集的结果已包含这些分支。[分支原始记录](../q9_junction_branch.jsonl) · [每叶证书](leaf_duals)

在工作区根目录运行：

```sh
python3 -B q9_junction_integer_audit/verify.py
```

输出的 `arbitrary_length_exact` 列出每组已单独复核的任意长度结果、锚点编号和证书。其余 `best_found_common_anchor` 仅验证恰好 192 条边的情形。所得锚点组按实验筛选，最少所需的锚点数仍未知。
