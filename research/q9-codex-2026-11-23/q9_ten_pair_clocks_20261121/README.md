# 将十维转向按五对分组后重新嵌入九维

给 Q10 母路径的十个轴取完美匹配，再指定其中一对合为 Q9 的轴 8。其余四对分别对应 Q9 的 (0,1)、(2,3)、(4,5)、(6,7)。每一步自由选该组中的任一轴，约束跨越完整时间序列。共有 945 × 5 = 4,725 种分组。固定时序和连续窗口，可平移起点至零，并借组内换轴固定每组首次使用的物理轴。

对首行的 315,036 个窗口已全部检查。相邻可行起点若不超过 26 步，先求解所有相应窗口共有的连续子段。若子段可行或未决，二分起点集合，最窄时检查完整 192 步。8159 种 UNSAT 子段在可逆向、可置换四个非单轴组的几何等价下覆盖所有 315,036 个位置，无未决。子段长 166–192 边。任何该母体上同规则的 195 或 196 边解，其前 192 边也是解，因此也均排除。额外在每条母体的七个起点上逐长度直接求解，192/195/196 筛后分别有 7499/3509/2676 种规范词，全部返回 UNSAT。计算为有限范围本地 SAT 结果，未生成 DRAT 或 Lean 证书。

## 必要条件

每个 Q5 商顶点以五组的奇偶位表示，其纤维含 16 个 Q9 点。商词若出现连续两个单轴、三个转向的第一和第三个同时是单轴，或连续三个都在同一二维组，都会重复顶点或产生弦。每个商点的访问次数均不得超过 16。

相邻纤维 L、R 之间，单轴方向形成含 16 条边的匹配。以 n、m 表示访问 L、R 的次数，e 表示两者之间的相继时间边数，则要求 n+m−e≤16。二维组方向在两纤维间形成八个互不相交的 K₂,₂。每个含时间边的连通分量都要独占一个 K₂,₂ 单元；三次连续本组转向已被排除，所以每个非平凡分量是一条边或一个二边星形。余下只在一侧出现的未匹配位置，同一单元同侧最多放两点，不同侧不能共用单元。置 a、b 为两侧在接触图的二度点数，所需单元数至少是 e−a−b + ceil((n−e+a)/2) + ceil((m−e+b)/2)。

## 复核与文件

- `filter.cpp`、`real*.log`、`all*.logtmp` 给出滑动筛选及原始起点范围。命令参数顺序为输入点文件、目标边数、行数、起点步长、蓄水池容量、随机种子、分组数、样本输出，以及可选的存活起点范围。完整排除用所有分组与步长 1，和蓄水池及其随机种子无关。
- `select.py`、`priority_selection.json`、`priority*.jsonl` 记录七起点计算。起点为 0、1、末位的四分之一、二分之一、四分之三（向下取整）、末位前一位及末位。
- `cover.py`、`cover192.log`、`cover192.jsonl` 是全部 192 窗口的子段搜索及逐次 SAT 记录。运行 `python -B audit_cover.py --sat` 从保存的 UNSAT 子段逐窗口复算覆盖，并用基于实际几何反例逐步补约束的独立编码 `lazy.py` 交叉求解 128 个子段。`audit_cover.json` 有每条母体的覆盖数。
- `positive.py` 从 Q9 真 191 转向词分裂一个轴并局部扰动同组内的其他转向，生成 15 条遍历全部十轴的 Q10 诱导路径。`controls.pts`、`controls.tsv`、`controls.json` 记录路径、输入词和祖先。每条的全部 45 种恒定并轴都产生缺陷。两种编码各独立恢复 15 个真 191 见证（共 30 次输出，允许重复）；每个都至少改动了刚性投影的两个转向。`audit.py` 对每个输出检查 18,336 对顶点及全部组标签，并用独立接触图算法交叉检查 5,760 个筛选窗口。原始高维输入也核验了上下界、互异和诱导邻接。`audit.json` 是复核输出。
- 对 1,912 条近解母体在存活实例中抽测 1,200 个，首轮 1,173 个 UNSAT，独立几何编码也关闭了其余 27 个。对 1,539 条扩展母体，195/196 各另抽测 250 个；首轮分别 242/237 个 UNSAT。近解样本有限。
- `near_low.cpp` 另从前述 239,673 个存活项选择刚性并轴后至多两个缺陷的实例，缺陷包括重复点和不相继邻接对。一个缺陷的 42,284 项、两个缺陷的 56,726 项，消除相同规范词后合计 95,672 个。抽测与复算保存在 `near_low_solves.jsonl` 和 `near_low_retry.jsonl`。

近解最终状态：5000 种低缺陷分组首轮 4924 个 UNSAT，独立编码补完其余 76 个，全部 5000 个 UNSAT。另对 256 个低缺陷词直接计算全部不相继点对，复核位掩码直方图的缺陷数及逐步转向。扩展母体的 195/196 两组抽样在分别补完 8/13 个未决后，最终均为 250/250 UNSAT。
