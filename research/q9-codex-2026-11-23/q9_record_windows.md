# 195 或 196 边的九维蛇至少含三类新的 191 边蛇

长度按边计。两条有向路径等价是指可通过坐标重排和平移逐点对应。若还允许颠倒路径，则称为无向等价。给定一条 195 或 196 边蛇，依次滑动长度为 191 边的窗口，一共分别有五个或六个窗口。每个窗口至少一端可伸长一步。Orland 等的 131 类公开 191 边蛇均无法从任意一端伸长，因此每个窗口都属于公开库以外的类别。[原文 §6.1](https://arxiv.org/html/2607.15270v3)

**任意两个窗口在给定的前进方向上都不等价。** 假设它们的起点相距 t 步，存在立方体等距变换 F，使得对于第一个窗口的每个顶点，都有 F(vᵢ) = vᵢ₊ₜ。把第一个窗口起点的序号定为 0，关系适用于 0 ≤ i ≤ 191。任意等距变换写成坐标置换 π 与逐位异或平移的复合。若 π 的阶为 m，则 Fᵐ 是平移，F 的阶 r 整除 2m。枚举 9 的 30 种整数分拆，坐标置换的最大阶为 20，只有循环型 (5,4) 取到 20。因此 r ≤ 40。

只要 rt ≤ 191+t，反复应用窗口关系就得到 v₀ = vᵣₜ，违反路径顶点互异。对 t ≤ 4 立即成立。对 t = 5，尚须处理 r = 40；若 r ≤ 39，仍有 rt ≤ 195。剩余情形的 π 在重标号后可固定为 (0 1 2 3 4)(5 6 7 8)。把每一步翻转的坐标写成 aᵢ，则 aᵢ₊₅ = π(aᵢ)。对全部 9⁵ = 59,049 种前五步逐一生成后续转移，首次出现重访或弦即停止。最长合法前缀为 44 边。故 t = 5 也无法产生有向等价。

每一无向类别至多包含两个不同的有向类别。因此五个有向类别至少给出 ⌈5/2⌉ = 3 个无向类别，六个也至少给出 3 个。该结论仅是较长蛇存在的必要条件。

在本目录执行 `python3 -B verify_q9_record_windows.py` 可核验循环型、剩余枚举规模和最大前缀。本论证没有进行 Lean 形式化。
