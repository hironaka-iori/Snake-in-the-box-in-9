# 固定 Q8 donor 的整数价格分支树

Q8 目录编号为从 0 起的行号。测试的三个转移词为 `q8_catalogue_96_98.words` 中编号 0、15、606。每一份根证书的原始整数价格保存在同名 JSON。编号 15 取自 `../q9_facet_bank_all8.jsonl`，编号 0、606 取自 `../q9_facet_bank_four.jsonl`。价格均未重新优化。

**结果**　三条 donor 的两种端点颜色均已排除 193 个顶点的诱导路径。该结论以整段指定 donor 出现在某个 Q8 面内为条件。转移词按 Q9 等距映射处理可直接推广到其同构像。长于 193 顶点的诱导路径若含这条 donor，也可以截成一个同时包含它的 193 顶点子段。

| donor | 多数色 0 根界（顶点） | 完整树节点 | 叶数（其中不可行局部因子） | 最大有限叶界，比例 10,000 | 多数色 1 的根界（顶点） |
|---:|---:|---:|---:|---:|---:|
| 15 | 193.5069 | 6,665 | 3,333（837） | 1,929,994 | 190.3231 |
| 606 | 193.2245 | 2,021 | 1,011（209） | 1,929,960 | 187.2755 |
| 0 | 195.3323 | 2,203,617 | 1,101,809（309,162） | 1,929,999 | 187.7594 |

以上 3 棵多数色 0 的树都只有整数上界或空局部因子剪枝。开放分支与完整赋值几何拒绝均为 0。多数色 1 的三棵树各在根处就严格低于阈值 1,930,000。编号 0 的较早 300,000 节点限额试验留有 11 个开放分支，最终结论使用 `i0m0_deep.tree` 及 `i0m0_deep.replay`。

## 计分与覆盖

对于指定的 Q8 donor，内部顶点必须占用，禁止额外使用它们除原路径之外的邻居。donor 的两端仍纳入残余顶点。(v) 的星因子列出中心及残余邻居的所有局部占用，选中中心时检查含 donor 内边的总度数为 1 或 2。未选中心对邻居不加限制。每个被计价的坐标面列出诱导线性森林，并检查端点和投影签名的兼容性。

根常数包括 donor 内部顶点和目标端点颜色、二部顶点数差的整数价格。星和面的同一签名价格在真实路径上相消，全体局部因子得分与根常数的和恰为顶点数乘 10,000。部分赋值下，保留符合已知局部占用的每个选项，并分别取星、面最高整数分。若某因子没有选项，或总上界严格小于 1,930,000，该结点被排除。其他节点选择一个未定残余顶点，树中按“不占、占”依次列出完整的两个子树。用于六个排除结论的树均无额外预置占用。

`model.py` 根据原始价格生成局部表。`check_tables.py` 采用姊妹目录独立复核器中的线性森林枚举，对所有可能的局部占用逐项核验是否存在及对应整数分，并独立重算根界。七套局部表核验结果在 `checked_tables.jsonl`。`tree.cpp` 以降分序筛选符合赋值的选项。独立的 `replay.cpp` 直接枚举自由位的所有子掩码，不依赖选项的分数顺序，逐叶重算上界并验证分支树完整性。`*.replay` 保存结果。这些是可重放的整数计算，未进行 Lean 内核证明。

## 真实阳性

`control.json` 来自 `../q9_facet_bank_replay_positive.jsonl`，附有目录编号 43 的 190 边（191 顶点）真实路径。以 191 个顶点为阈值，预置 127 个残余占用状态，留下 36 个自由顶点。搜索在 75 个节点内恢复一条真实 190 边路径，并将一个完整但几何不合法的赋值排除。独立树重放逐对核验了路径。另一条对照不预置任何顶点，按已知见证依次处理全部 163 个变量，最终见证分值恰为 191×10,000。该对照保留 109 个未展开旁支，记录在 `control_unpinned.replay`。

## 复跑

从本目录执行。负例全树只需要一个 C++20 编译器及标准 Python；核验依赖姊妹目录现有的 `q9_facet_dual_replay.py`。独立树重放器也支持任意位置的兼容表、树文件和可选外部固定点清单。

```sh
python3 -B model.py
python3 -B check_tables.py i15m0 i15m1 i606m0 i606m1 i0m0 i0m1 control
clang++ -std=c++20 -O3 tree.cpp -o tree
clang++ -std=c++20 -O3 replay.cpp -o replay
./tree i15m0 i15m0.tree 193 300000
./tree i606m0 i606m0.tree 193 300000
./tree i0m0 i0m0_deep.tree 193 4000000
./replay i15m0.tables i15m0.tree 193
./replay i606m0.tables i606m0.tree 193
./replay i0m0.tables i0m0_deep.tree 193
./replay i15m1.tables i15m1.tree 193
./replay i606m1.tables i606m1.tree 193
./replay i0m1.tables i0m1.tree 193
./replay control.tables control.tree 191 control.pins
python3 -B control_walk.py
./replay control.tables control_unpinned.tree 191
```
