# Q10 两张切片的独立等距投影

固定 Q10 的控制坐标 h，删除它得到两个 Q9 切片。第零片采用任意全局坐标约定，另一片允许任意九轴置换 P 及异或平移 b。母蛇沿时间顺序每次跨片都必须成为 Q9 的一步。每张片多次出现时沿用其映射。已有 q9_three_seam_folds 将时间截成三个连续片段；q9_dynamic_fold_20261120 在一个时间区间内改变折叠规则。这里的切换取决于顶点的控制位，可以任意多次往返。

**在原始 12 条各 379 边的 Q10 母蛇上，这种构造的最大值精确为 190 边。** 每条母蛇的第一个 190 边窗口对十个控制轴都可行，其余所有 190 边起点均不可行。191 边全部窗口无解，故更长合法窗口也不可能存在。两种无节点截断的枚举器分别计算了 190、191、192、195、196 边，给出完全相同的命中行。192 边另关闭公共子窗口剪枝，将 22,560 个实例逐个重算。

## 枚举原理

切换处在两个原切片上投影到同一个坐标 s。其像必须相邻，故若未变换切片固定，第二片的平移必为 s XOR P(s) XOR 2^j，其中 j 有九种可能。两个同片顶点间的距离由等距变换保留。对来自另一片的顶点，排除与固定片重合的像，并且只允许原时间相邻的跨片点对在像中相邻。

charts.cpp 从源侧逐轴指派目标坐标，将每个顶点允许的 512 位像集与相应目标半立方体取交。independent.cpp 从顶点像反推坐标分块，分别统计每个已知源坐标块和对应目标坐标块中取值为一的轴数，逐次细分到所有点像已确定。两者的搜索方向和相邻窗口合并粒度不同。公共子窗口不能投影成功时，包含它的所有窗口也不能成功。

“轴窗口”指母体、控制轴、窗口起点三元组。在每个目标长度均穷举指定输入集的全部三元组。所有表中目标均为零命中。同一几何片段可能来自多条母体。

逆提升的 1,912 条母蛇来自 997 个不同的近路径源样本。768 条的原投影带一条弦，1,144 条带两条弦。所有提升结果均独立核验为真正的 Q10 诱导路径，每个源输入文件内整条路径按平移、坐标改名、反向去重。额外取得的 296 个子段亦逐个与高维母体的记录位置比对。

## 阳性与回放

从有效 Q9 的 191 边档案逆提升 16 条满十轴路径，每条在指定轴跨片 7–10 次。固定该轴时，删除控制位后仅作平移，所有可能的平移都失败。两种枚举器各自 16/16 恢复 191 边。controls.log 第 1 行的源路径跨片 8 次，程序给出置换 152348670、平移 1，输出从 0 到 266。192 个点的 18,336 个无序点对中，恰好只有 191 个连续点对相邻。1,120 条生长子代中另有 14 个 191 边窗口通过，归入 9 个已知 Q9 规范类。

在本目录运行。输入和输出均在本地。audit.py 仅用 Python 标准库完成来源和几何复核。所有候选搜索始终固定每张片的全局映射，结论限于表中的有限母体。

```sh
c++ -O3 -std=c++20 charts.cpp -o charts
./charts ../q9_three_seam_folds/q10_12.txt 192 0 11 -1 12 -1
c++ -O3 -std=c++20 independent.cpp -o independent
./independent ../q9_three_seam_folds/q10_12.txt 192 -1 7
python3 -B audit.py
```
