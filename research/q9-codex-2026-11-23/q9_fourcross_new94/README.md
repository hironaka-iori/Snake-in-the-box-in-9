# 从两条 189 边新布局构造四跨 Q9 路径

两个输入均来自上轮 reroutes/move 的 94 边下层母段和真实上臂。目标路径恰跨第8号坐标四次，下层由两个互不邻接的诱导段组成。本轮最佳为 **184 边**，没有发现192边。

## 连续截短的几何限制

若从原94步主段的任意一端或两端合计剪去1或2步，每个种子有两个93边、三个92边窗口。独立重建十次下层闭邻域后，九个窗口的剩余图无边，一个窗口的剩余图只有一边。两种下层片段之间不能相邻，因此十个连续截短方式都放不下至少3边的第二段。逐例数据见 trims.tsv 和 audit.json。

第一行从原供体截取长核心，另选相容的短段，并在完整Q8中从核心两端重长。45,000次抽样给出六个有向记录，按原始坐标占用去重是三种下层森林。whole.py 固定下层，开放整个上层找回两个184边有向路径。两者的转移词经首次出现重编号及反向规范化后仍不同。见 freer92.dat、free184.paths 和 free184.jsonl。

witness184.json 给出完整185顶点和转移词。上、下、上、下、上五段分别有68、3、12、92、5边，另有4条跨层边；跨层步的位置从0起为68、72、85、178。audit.py 逐对核对17,020对顶点，核实端点、下层占用、五段结构、以及与第1号原母段共享的连续63步。

表中另外三行为部分移植。扫描本地库的21,197个规范92/93词后，发现131个可在闭邻域外放下独立3边短段的主段（122个92步、9个93步）。每个移植将主段中的连续匹配核心用等距变换实际对齐到指定新供体；其余部分使用八维库几何。第一种子保留约40步或更长时的其它直接搜索未得到92/93步的成功布局。保留第一种子整段84连续步、另一段8步时，另有176边的四跨阳性，见 control.paths。

## 192 边尝试

- 固定上述六个第1号种子的92步有向记录，重建上层的两种同色端点情形，先用10万冲突，后用15万。最终12次求解均返回 UNSAT，其中含重复下层几何。第0号种子三种92步移植记录分别试两色，每色8.5万冲突，三次 UNSAT，三次未决。
- 93步移植按保留两片完整占用集合的平移、轴置换和主段反向去重后有10个几何。对每个几何分别检查上层两种端点颜色，各6.5万冲突，15次 UNSAT、5次未决。全程以实际构造为目标，本批次没有生成不可满足性证书。
- joint.py 同时放开上层、下层主段的两个跨层口及主段外形，只保留下层3步短段、主段92步的精确长度及原供体中的一个连续核心。分别固定第1号供体54/63步核心以及第0号供体24步核心，192边的六种端点分支各设10万冲突。三次求解返回 UNSAT，三次未决。184边阳性在54和63步核心下均成功找到。附加188或186边尝试均未决。
- 从两条184见证分别在一个垂直端口两侧各放开至多31步，容许主段长度92或93、短段3至8，以192为目标搜尽3,656个指定窗口，未得见证。详见 p192.log。这项局部结果以及上述样本都不构成四跨族的上界。
