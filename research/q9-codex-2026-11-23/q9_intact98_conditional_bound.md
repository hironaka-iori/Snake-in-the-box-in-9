# 保留一条指定八维 98 边母蛇时，九维蛇至多有 186 边

**条件定理。** 设九维超立方体的一条诱导路径在某个八维面中包含下列母蛇的全部 99 个顶点，则该九维路径的长度至多为 **186 边**。交换坐标、翻转坐标位或反向读取路径都保持结论。因而要从这个母体构造 192、195 或 196 边的蛇，至少要舍弃这个副本中的一个顶点。其他八维 98 边母蛇是否与这个副本等价，需要单独验证。九维最长蛇的精确值仍然未知。

从八维顶点 0 开始，以 0 至 7 表示每步翻转的坐标，这个母体的 98 步为

```text
01231041543146340134674310427401475140163104154314234013427431046740147561340142741043164104764013
```

两端点编号为 0、78。按顺序把 99 个顶点各存为一个字节，SHA-256 为 `3a6f7de01ad1631d87955d86be8668c43ec352dbb76f9927591cb524b8e9e78c`。完整序列见[母蛇顶点记录](q8_free_layer_full98_duals.jsonl)。

## 为什么可以枚举所有跨层方式

把含母蛇的面称为下层，另一个面称为上层。母蛇内部的 97 个点在九维路径中已有两个邻居。枚举下层全部 256 个顶点，母蛇外只有 61、144、240 与这 97 个点均不相邻。它们也均不邻接母蛇两端，三对之间的汉明距离分别为 5、5、2。任一被选的额外下层点只有正上方可能接入整蛇，因此它必为整蛇的端点。

从母蛇跨到上层的低端只能是 0 或 78。两个母蛇端点都不跨层时，含有完整母蛇的诱导路径就是母蛇本身，长度为 98。其余情况选定跨层的母蛇端点、额外下层端点及整蛇两端的二分图颜色后，得到 22 个分支。每个分支确定下层点集、全部跨层边、上层需要的各色端点数，以及上层所选两种颜色的数量差。

## 22 个分支的整数上界

每个上层顶点枚举是否选取和可用的入射方向。每个指定坐标方向族中的每一个仿射小立方体，独立枚举所选顶点，保留其诱导子图为森林且局部度数相容的选择。真实路径在这些枚举中必有对应选择。把证书的整数权重分给顶点和小立方体，两边对同一局部选择的权重符号相反，相加抵消。因此，将各项独立取最大值再求和，可上界上层的顶点数。若下层有 N 点，上层权重总上界为 D，比例因子为 s>0，则总边数至多是 N-1+⌊D/s⌋，再向下取到端点颜色允许的奇偶性。独立校验器用整数重新计算这些最大值，并核对分支是否完整。[全分支整数证书](q9_intact98_all_crossing_certificates.jsonl) · [校验器](verify_q9_intact98_all_crossings.py)

## 从 188 收紧到 186

只有第一行还需收紧。此时下层恰为 99 个母蛇顶点，上层为从一个指定根出发的单条诱导路径。记上层顶点数为 U，整蛇有 98+U 边。对于奇数 U，根 0 与根 78 的两份整数证书分别给出 U≤ 8,895,953/100,000 和 U≤8,885,923/100,000，所以两种方向均有 U≤87。如果存在偶数 U≥90，删除上层的游离端点可得到以同一根出发、至少有 89 个点的奇数上层路径，矛盾。因此 U≤88 且 98+U≤186。与其余 18 个分支合并即得定理。[单根奇数点证书](q8_intact98_single_odd_duals.jsonl) · [完整校验输出](q9_intact98_all_crossing_verified.json)

## 复核

在本目录运行以下命令。仅需 Python 标准库。输出中的 `verified_records` 应为 22，`overall_edges_upper` 应为 188，`combined_edges_upper` 应为 186。

```sh
python3 verify_q9_intact98_all_crossings.py --single-odd q8_intact98_single_odd_duals.jsonl
```

本次验证给出这条指定母蛇的条件上界，尚未确定在该条件下是否有一条恰好 186 边的蛇。要将结论推广到所有八维 98 边母蛇，还需要覆盖所有非等价形状。
