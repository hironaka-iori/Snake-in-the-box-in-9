# 八维 96 边母蛇与九维单次跨层核验

本轮构造了 **450 个冻结合并库之外的八维 96 边无向同构类**。其中两个是一条既有 97 边路径的端点截段。在所检查的项目历史文件中，其余 448 个没有匹配记录。这里的新增范围限于本地比较材料。八维最长路径的数值没有因这次构造而改变。

每条路径的转移串、首次出现的搜索阶段及历史归类均列于 [mothers.tsv](mothers.tsv)。从顶点 0 出发，每读到数字 (d) 就翻转第 (d) 位。每条 96 边路径恰有 97 个不同的八位顶点。独立验证器逐一检查了这 450 条路径的全部 2,095,200 对顶点，确保汉明距离为 1 当且仅当两点在路径中相邻。表中还附有一条经核对后确认已经出现在项目历史日志中的 97 边路径。[历史 97 边证人](evidence/previous_97.json)

## 搜索如何得到这些形状

| 阶段 | 构造 | 新增 96 边类 | 新增到冻结库的 97 边类 |
|---|---|---:|---:|
| segment | 在两个固定锚点之间移去一段，再枚举能接回的诱导路径 | 84 | 0 |
| regrow | 随机截去单端一段，再从端点向不同方向生长 | 91 | 0 |
| level96 | 一换一顶点重排，保留可反向重接的子路径，并试加端点 | 82 | 1 |
| level95 | 允许暂降到 95 边，再经重排和端点生长回升 | 90 | 0 |
| level94 | 允许暂降到 94 边，再经重排和端点生长回升 | 103 | 0 |
| **合计** | | **450** | **1** |

冻结库在 96、97、98 边分别有 221、25、1 个无向类。与本轮输出合并后分别为 671、26、1。对转移串按坐标首次出现顺序重新编号，对正序与倒序取字典序较小者。这样消除了起点平移、坐标置换和路径反向。[冻结输入清单](evidence/baseline_manifest.json)

历史核对另扫了项目根目录中以 `q8` 开头的 `.json`、`.jsonl`、`.txt`、`.log` 文件，比较可识别的 96 至 98 边转移串、显式顶点集合中可重建的单条路径，以及这些路径的长截段。该扫描没有覆盖外部文献、其他目录或所有可能的历史编码。[匹配明细](evidence/history_audit.txt)

## 九维单次跨层结果

每条新母蛇还取了全部 93 至 96 边连续截段，并保留两个根端方向。连同补录的 97 边路径，与冻结库去重后，按 93、94、95、96、97 边分别增加 2,888、2,246、1,568、900、2 个有向根臂。对每个新增根臂，程序检查给定库内两臂的每个够长配对与全部 (8!) 种相对轴置换。将两根投影对齐在 0，再跨过第九维一次，所得长度等于两臂边数之和加 1。其余投影点必须互不重合，否则产生额外跨层弦。

| 九维目标边数 | 有向配对与置换的尝试数 | 有效拼接 |
|---:|---:|---:|
| 192 | 145,142,484,480 | 0 |
| 193 | 39,246,197,760 | 0 |
| 194 | 2,062,287,360 | 0 |
| 195 | 76,769,280 | 0 |
| 196 | 161,280 | 0 |
| **总计** | **186,527,900,160** | **0** |

两臂同属某一新增批次时，有向配对可能重复表示等价放置。上表是实际循环次数。这个结果排除了指定库中至少一臂为本轮新增根臂的单次跨层构造。其他母蛇、多次跨层的一般九维路径仍开放。独立阳性对照取已有的 (96+1+94=191) 边九维路径并逐对检查；阴性对照分别含四边形弦、重复顶点和非立方体边。[191 边对照证人](evidence/control_191.json)

## 复核与复现

Python 3.10 以上可直接执行下列命令。默认检查全部证人、同构去重、五批次分类与计数、三个阴性对照和一个阳性对照，并按各长度的根臂数独立重算上表每行的总数。

```sh
python3 verify.py
```

以下两个选项分别重新生成五批原始构造与重新枚举全体有向放置。二者会在临时目录中编译附带的 C++ 程序。生成时用到的伪随机搜索在原机以 clang++、C++17、libc++ 运行，其他标准库的随机排列实现可能产生不同批次；默认的证人核对不依赖这些随机过程。

```sh
python3 verify.py --regenerate
python3 verify.py --replay-joins
```

每批次的原始证人和跨层枚举末行计数存于 [evidence](evidence)，编译所用源码存于 [src](src)。这是有限构造和 C++ 枚举的证据；此次没有进行 Lean 内核验证。
