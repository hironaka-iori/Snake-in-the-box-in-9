# 两个八维母体加至多两个外部顶点时，最长九维诱导路径为 191 边

从本地 `q8_catalogue_96_98.words` 的 753 条八维诱导路径中任选两条（允许相同），分别放进 Q9 的两个平行八维面。允许两条路径任意相对平移和坐标置换，能从中删任意点、改变顺序和多次跨层；还可以使用两条母路径顶点集并集以外的任意两个九维顶点（也可以只用一个或不用）。对此构造族，最长开放诱导路径为 **191 边**。结论适用于该文件列出的形状。

**达到 191。** 在两条库内母路径的连续片段中，能取到一条 96 边臂和一条 94 边臂。根部相隔一个跨层边，得到 96 + 1 + 94 = 191 边。两条母体在各自面内的摆放和结果的 192 个九维顶点均保存在 `q8_catalogue_lifts_verified.json` 的 `lower_certificate`。核验器逐对检查 18,336 对顶点，并重建两段各自在源文件中的位置。

**排除 192。** 输入有 726、26、1 条长度分别为 96、97、98 边的路径，逐条通过诱导路径检查，按坐标置换、平移与反向去重仍为 753 条。无序且允许重复的配对数为 753 × 754 / 2 = 283,881。每对有 256 × 8! 个带标号的相对等距变换。总覆盖 2,930,196,971,520 种配对与摆放组合，包含对称等价的摆放。程序成组排除其中的大部分。

设两臂共有 N 个九维顶点，八维投影重合 c 个点。宿主诱导图有 N − 2 + c 条边，最大度至多 3。选取一条恰好 192 边的路径，若它有 e 个顶点在宿主外，宿主中需要删除 k = N + e − 193 个点。删除这些点至多移去 3k 条原有边；保留的宿主顶点作为路径的诱导子图，至多有 N − k − 1 条边。因此 c ≤ 2k + 1。对 e ≤ 2 可按最大的 k 过滤。任何更长诱导路径都有 192 边的连续片段。

主程序以代表母体的重合量扣除两边缺失的点数，给出实际重合量的下界；复核程序直接计算每组所有母体所共有的顶点，依据两组公共点的重合量过滤。对于不允许外部顶点的情况，两种程序均保留 16,027 个摆放进一步搜索。允许至多一个外部点时，两种程序均保留 106,435 个；放宽到两个时，均保留 710,035 个。对这些摆放，主程序在度数超限的顶点及其邻居上分支删点；复核程序枚举必须击中的三叉星，并检查剩余路径分量或环。三种外部点预算的全库复核均未得到 192 边路径。独立程序还与四维中所有诱导路径对照了 3,600 个小实例，并从四个分别需要补回零、一、二、三个外部顶点的真实 191 边对照中找回路径。证据为可重跑的原生程序和显式顶点见证。

## 复核

`verify_q8_catalogue_lifts.py` 核查 753 条母体、191 边见证、配对计数与运行日志。独立复核器可从已验证的分组输入重新计算各外部顶点预算下的上界。

```sh
python3 -B verify_q8_catalogue_lifts.py
c++ -O3 -std=c++20 verify_q8_clustered_hosts.cpp -o /tmp/q8-independent
/tmp/q8-independent 192 0 < q8_registered_donor_clusters.txt
/tmp/q8-independent 192 1 < q8_registered_donor_clusters.txt
/tmp/q8-independent 192 2 < q8_registered_donor_clusters.txt
```
