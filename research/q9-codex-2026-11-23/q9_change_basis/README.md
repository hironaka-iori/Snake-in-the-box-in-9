# 九维点集换基与补点搜索

给定候选点集，选九个线性无关的九位向量作新基。原始标签异或为某个基向量的两点在新坐标中相邻。这样同一批点可以按不同次序形成路径。路径长度均按边数计算。程序对每次返回的路径输出九个基向量及完整的九维顶点序列。

## 枚举方法

任何基都对应唯一的非零线性泛函，使九个基向量的函数值都为 1。路径沿两种函数值交替。程序用此条件筛除颜色总数不允许的泛函。每个差向量在给定点集上贡献一个匹配。逐个选取匹配时若某点度数已经达到 2，再经过该点的匹配就不可能加入。九个匹配选齐后，仍须检查基的秩、边数、连通性并恢复次序。

如果还允许添加 k 个任意位置的新顶点，原有点必须构成至多 k+1 个路径分量，可含孤立点。此时搜索原有点间从 n-1-k 至 n-1 条边的情况，排除成环分量。依次在分量端点旁加入未占用的九维顶点，可以连接若干分量或延长端点，直至得到目标长度。focus.cpp 进一步要求新增点贴着当前最大分量。任何连通的最终扩张都至少含一个这样的新增点。它也用各分量端点间的最小生成树距离下界剪枝。

## 文件与复算

- general.cpp 对完整给定点集枚举基，检查是否成路径。也可检查已连成单条路径的候选能否从端点延长。
- augment.cpp 和 forest.hpp 枚举允许原有点分属多个分量的补点情形。用第五个参数启用。focus.cpp 和 forest_focus.hpp 是面向更多空位的版本。
- inputs.py 从八维拼接产生的九维近解生成定长窗口，剔除重复顶点，并按步序的坐标重命名及反向去重。窗口只是本地数据来源的子集。
- check.py、general_controls.py 和 forest_controls.py 核对阳性见证的所有顶点对，以及返回点集与原点在逆坐标变换下的关系。general_controls.py 对无原单位向量的随机基变换打乱点集顺序；forest_controls.py 额外删除内部顶点。
- coverage.json 汇总逐个点集的日志。CLOSED 表示枚举器完成该有限分支，UNKNOWN 表示达到节点预算。当前结论均为本地计算结果，未生成 Lean 证明。

从本目录复算一个全换基实验及一个允许任意补点的实验。

```sh
c++ -std=c++17 -O3 general.cpp -o general
c++ -std=c++17 -O3 augment.cpp -o augment
./general 192 1000000 0 < windows192.txt
./augment 192 1200000 0 grow < ../q9_gap_generations/prior191.words
python3 -B summarize.py
```

旧版 find.cpp 的端点检查每端最多尝试补一步，在需要同端连续补两步时会漏解。现版本枚举两端步数分配及每一步的全部方向。tip_regression.log 保存了原档案第 0 条母蛇的 189 边前缀在修正后恢复 191 边的记录。任意内部补点的实验使用独立的森林扩张过程。
