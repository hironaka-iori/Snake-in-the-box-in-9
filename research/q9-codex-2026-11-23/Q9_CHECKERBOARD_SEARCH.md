# 从八维投影的半个棋盘重建九维开放蛇

本轮目标是九维至少 192 边，即至少 193 个互异顶点，两顶点汉明距离为一当且仅当它们在序列中连续。本轮可逐点验证的最高长度为 191 边。

## 保留一半信息后，哪些构造已封顶

选一个九维坐标作为上下层。给剩下八个坐标的每个点按汉明重量奇偶染色，于是 256 个八维点分成各 128 个点的两色。固定一种颜色上的九维顶点配置，即指定每列的上、下两点各自是否出现。另一种颜色的 256 个九维顶点全部自由选择，遍历顺序也自由。

取[作者的公开路径库](https://github.com/Math-AI-Caltech/Snake-in-the-Box)中的 131 条 191 边路径，各取九个投影方向和两种颜色。2,358 份记录按明确坐标下的配置去重后得到 1,602 份。对每份配置，上界和下界均为 191 边。下界由相应原路径达到。[冻结输入](q9_port_followup_public191.txt.gz) · [1,602 份配置](q9_projected_checkerboard_sets.txt)

上界检验为每个配置建立独立 CNF，要求至少 193 个顶点、每个选中点的度数为一或二、度数为一的点至多两个。所有满足目标的开放蛇都符合这些条件。1,602 个公式均已生成 DRAT 不可满足证书并经 drat-trim 验证；从存盘压缩包重建公式后又完整重放了一遍。这些公式甚至无需添加排除额外环分量的约束。[证书包](q9_checkerboard_191bank.drat.jsonl.gz) · [复核程序](certify_q9_checkerboard.py) · [二次重放结果](q9_checkerboard_drat_replayed.json)

## 改变这一半，能否升到 192

对每个固定半棋盘，将某个原本选中的九维顶点删去，或将原本未选的一个顶点加入。每个配置有 256 个不同的这种改变，另一半仍完全自由。全部 1,602 × 256 = **410,112** 个“配置、变动位置”组合均已排除。四状态回溯直接判定了 337,653 个，另 72,459 个由独立 SAT 实现返回 UNSAT。一批独立运行的 SAT 搜索还覆盖了其中 16,384 个组合。不同基准可能产生相同的变动后配置。[覆盖核验](q9_checkerboard_verified.json) · [回溯器](search_q9_checkerboard_states.cpp) · [SAT 补全](search_q9_checkerboard_walk.py)

这样得到一个搜索必要条件：若有至少 192 边的蛇，在任一投影方向和任一棋盘颜色上，它的九维顶点配置必须与相应颜色的每个记录半棋盘相差至少两处。这里的差指选点位的对称差。固定配置的排除有 DRAT 证书，单点变动的排除依据有限枚举及 SAT 运行记录。

还测试了 205,056 个成对变动，以及 588,793 个可逆二进制线性或仿射变换的组合，两批均未取得目标。前一批在每份配置上取 128 对，后一批的变换至少移出四个固定点并加入同样多的点。它们各自只覆盖实际测试的变动。故意损坏一个及两个位置的阳性对照均重建了 191 边蛇，并逐对检查了其顶点。[单点修复对照](q9_checkerboard_one_repair_control.log) · [双点修复对照](q9_checkerboard_pair_repair_control.log)

两条不同母蛇的八维子面也进行了移植。11,957 个不同投影集合在允许所有层选择与顺序后均无法容纳至少 192 边的蛇。以 191 边为目标的次级实验重建了 8 条路径，属于 7 个公开已知类。在另一批交替改变棋盘颜色的搜索中，构造出了 138 个不在本次 189 边种子文件中的 189 边类；继续做二、三、四点替换的这一批没有产生更长的见证。[子面移植核验](/Users/yichenzhan/Documents/Codex/2026-11-20/q9-projection-face-graft/audit.json) · [逐例增长记录](q9_checkerboard_walk_exchanges.jsonl)

## 复核

在本目录使用装有 PySAT 的 Python，并给出 drat-trim 的可执行文件路径，可重算 1,602 份条件上界证书，再核对输入、覆盖与阳性路径。

```sh
python certify_q9_checkerboard.py /path/to/drat-trim q9_checkerboard_191bank.drat.jsonl.gz --replay
python verify_q9_checkerboard_search.py
```

这些结果限制了与公开路径相近的一批构造。九维全局最大值以及 195、196 是否可达，仍未确定。
