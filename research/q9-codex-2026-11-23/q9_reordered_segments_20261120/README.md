# 九维诱导路径的分段换序搜索

从 800 个互不同构、带一条弦的 192 边游走出发，切掉 3 或 4 段内部顶点，在原位置保留其余块。每个完全位于八维子立方体的 96 边输入窗口至少去掉一个顶点。保留块可交换先后次序、翻转，每两个新相邻块再用九维短桥连接，最后允许延长两端。每个输出的全部顶点都记录在日志中。

自由端段实验的 240,000 次尝试里，238,214 个切分进入搜索，146,169,010 个次序和翻转组合通过粗略距离筛选，29,161 次重连通过兼容性检查。同一条路径可多次重连生成。按平移、坐标置换、整条反向去重后，逐对检验得到 614 个 190 边类和 131 个 191 边类，未得到 192 边。全部 191 类都出现在原先的 131 类参照库中。其中 106 类完全不含冻结的 726 个八维 96 边母蛇类。614 个 190 类中，376 个未出现在从这些参照路径直接剪掉一端所得的 246 类中。这个比较只涉及指定的参照库。

固定两端块的位置时，2,500,000 次尝试得到 61 个 190 边类和 49 个 191 边类。受控测试从指定的已知 191 边真路径删去 6 个顶点并打乱两块，搜索按次序 0、2、1、3 和桥内部顶点数 1、2、3 重建了原路径。两个实际搜索都限制桥深、末端延展长度和抽取的切分，因此不能推出九维上界。

## 复算

在本目录执行以下命令。前两次搜索的确定性重放以 macOS 自带的 clang++ 和 libc++ 为准。

```sh
clang++ -std=c++20 -O3 search.cpp -o /tmp/q9-reorder
/tmp/q9-reorder 191 1 20 8 4 < control_input.vertices
/tmp/q9-reorder 192 0 2500000 11 9 601353 < ../q9_onechord_expanded_800.txt
/tmp/q9-reorder 192 0 240000 12 10 791142 1 1 < ../q9_onechord_expanded_800.txt
python3 verify.py
```

独立 Python 脚本检查每对顶点，要求汉明距为 1 当且仅当它们在序列中相邻。它还复核编号范围、顶点互异、证据去重以及参照库交集。程序输出存于 verified_summary.json。完整路径分别在 near800_deep.log、free_terminals.log，阳性在 control.log。reference191.words 为原有三个本地参照库归并后的 131 个无向类。输入不含上界信息。
