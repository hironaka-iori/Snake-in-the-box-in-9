# 七个双弦近路径的四块刚性重组

**完整保留 193 个原点时，七个近路径均不能通过这种重组变成 Q9 的诱导路径，哪怕允许增加任意数量的连接顶点。** 这里每条母路径可沿最多两个源坐标超平面切开。每块独立作任意坐标置换、坐标翻转及平移，允许跨块连接和整条路径的顺序完全改变。每一行只处理它自己的块。删除原点后的结果另见下文。

q9_via_q10/monotone_near.words 共 445 行，其中恰有七行长 192 步且只有两条弦。零基行号为 401、435、436、439、440、442、444。每行均有 193 个不同顶点，两个弦端对都包含时间指标 96。若保持原时间次序，则必须沿两条弦各自对应的轴切开，才能改变这两对点的距离。允许重接时直接枚举全部 36 种轴对。

## 无限制连接点的排除

若最终得到一条诱导路径，则保留的任何顶点子集本身必须诱导出无圈且最大度不超过 2 的图。添加新顶点无法消除原点间已经存在的边。

1. 七个母体共有 252 个双轴切法，其中 241 个已经在某个单块内部出现度至少 3 的点。其余 11 个切法中的每一块都是 Q7 中的刚性点集，其目标承载面可为任意七维坐标面。
2. 对这 11 个切法的每一对块，将第一块规范化到高两位均为零的 Q7 面；遍历第二块省略的两个物理坐标、其余七轴的全部 7! 个置换，以及使两张承载面相交的所有平移。这给出 4,811,304,960 个相对摆放。没有一个能同时避免已选点重合及度数超限。overlapping_pairs.cpp 逐摆放检查；bitcheck.cpp 对允许的平移作位集交，两次结果一致。于是若能保留全部块，四张承载面必须两两不交。
3. 四张两两不交的 Q7 面恰好覆盖 Q9。每个面固定两个坐标。两个面要不交，它们各自固定的轴对必须相交且在一个共同轴上取相反值。一族两两相交的二元集要么共享一个轴，要么是一个三角形的三条边。在四个面中，若后一情形出现，必有一条边重复；另两条边分别迫使这两个重复面的两位取相同值，无法不交。因此有一个共同切分轴，每个 Q8 半部中各有两个相对 Q7 面。两半的第二个切分轴可以不同。
4. 枚举把四块分到两个 Q8 半部的三种配对。枚举半部内的 42,577,920 个相对等距，获得 95 个度数可行半图；其中 92 个无圈，无任何端点数或孤点数限制。all_signatures.tsv 保存每个半森林的母体、轴对、坐标置换编号、平移、度缺额和孤点数。它们组成 22 个跨两半的互补组合。
5. 对每一组合，枚举两半之间所有 8! × 256 个相对等距，共 **227,082,240** 个摆放。零个使全体原点的诱导图最大度不超过 2。forest_join.cpp 以位集排除平移，direct_forest.cpp 逐平移逐点核验。两者结果一致。由于少切一次或不切也可在二次切割后让子块沿用旧图，本结论覆盖“最多两刀”。

## 实搜与阳性

- 保序自由图另作直接搜索。七个双弦输入都没有得到有效 192。固定原时序，释放点 96 并允许替换为任意 Q9 顶点时，252 个轴对实例全部穷举。再释放另一个弦端、95、97 或原路径端点，1,512 个实例全部穷举，无 192。
- 自由重接并允许替换点时，对每条的两条弦所对应的轴对另做 7 个单孔和 42 个双孔实例。目标面可按两半不同方向铺满立方体。没有发现 192。这些修补试验不排除任意删点的其他重组。
- 24 个来自真实 191 边档案的四块乱放对照，平行目标面求解器 24/24 恢复。另在两半故意采用不同切分轴构成 18 个对照，自由目标铺面搜索 18/18，平行目标面搜索 1/18。对这 18 个输入删去一处顶点再插回，自由接线恢复同样为 18/18。
- 取三个真实档案的 168 边连续子路，安排一半内的两个已占七维面真正相交，再独立打乱成员点集。允许相交面的搜索 3/3 找回有效 168 边，并逐行重建输出面方向。最后两半拼合的全枚举另在一个 191 边阳性上找到了两个完整连通的解。
- audit.py 独立重建各阳性输出的坐标图与全体顶点，直接检测每个无序点对，并重建全部 92 个半森林的几何、度签名与无圈性。每个 191 边回放包含 18,336 个无序点对。

完整计数见 audit.json。例证见 partition_control.log 第 1 行的 191 边和 intersects_control.log 第 1 行的 168 边。

```sh
c++ -O3 -std=c++20 bitcheck.cpp -o bitcheck
./bitcheck target.in independently_possible.tsv 252
c++ -O3 -std=c++20 all_half_forests.cpp -o all_half_forests
./all_half_forests target.in all_signatures.tsv
c++ -O3 -std=c++20 direct_forest.cpp -o direct_forest
./direct_forest target.in all_signatures.tsv direct_forests.tsv
python3 -B audit.py
```
