# Review of residual-symmetry search implementation

Read `scripts/history_solver.c`, `scripts/run_search.py`, and the imported `scripts/history_model.py`. No compiler, search, or software test was run. No unsound deletion or branch-coverage defect was identified for inputs generated by this wrapper. This is a source review, not a verification of a compiled executable or a completed search result.

## Domain and queue propagation

The C reader checks alphabet bounds, domain and row masks, distinct ordered constraint pairs, forbidden-tuple entries, and bijectivity of each supplied word map. Reverse binary tables are constructed as exact transposes. Arc revision retains a value precisely when it has support in the current neighbour domain, so every binary deletion is sound.

Every domain change enqueues all incoming arcs, including the immediate reverse arc. Duplicate queue entries are suppressed. There are at most $n(n-1)$ possible directed arcs and the ring capacity is larger than $128^2$, so the stated $n\le128$ bound accommodates all simultaneous entries. A capacity error exits unsuccessfully; it cannot report exhaustion.

The queue is global, but its use is safe in this depth-first implementation. Each recursive call resets and consumes it during propagation before making any child call. A parent resumes only its branch loop, which does not depend on the child's queue state. Each child receives a separate copy of the parent's active domain array.

After binary propagation, the forbidden-tuple rule is exact unit propagation: skip a tuple already impossible in one domain; reject a forced forbidden tuple; with one nonsingleton domain, remove that tuple's remaining value. These removals enqueue affected arcs. A domain reaching zero immediately rejects the branch.

The propagation loop repeats after any forbidden-tuple or lexicographic deletion. Binary propagation itself drains all queued consequences. Hence returning success with no further nonbinary alteration is consistent with the intended fixed point.

## Lexicographic scan

For each supplied permutation, the reader computes exactly the masks for fixed words and words satisfying $u\le\pi(u)$. The scan starts at the first chronological variable and reaches a later variable only after every remaining value of each earlier domain was found fixed by that permutation.

At the current variable it removes $u>\pi(u)$, immediately rejects an empty domain, and stops if any retained value is not fixed. Since retained nonfixed values satisfy $u<\pi(u)$, this is exactly the safe stopping condition established in `symmetry-review.md`. It handles mixed fixed/smaller domains correctly and does not continue merely because a domain is a singleton.

Every scan deletion therefore preserves every assignment satisfying the relevant lex inequality. Subsequent scans and binary propagation only remove values; they never invalidate the reasoning used for an earlier deletion. Identity permutations make no changes.

The C input validation checks arbitrary alphabet permutations, not their geometric meaning. That meaning is supplied by the wrapper: its coordinate order fixes block coordinate zero and permutes all remaining coordinates. The generated maps are precisely the 24 residual permutations for five block coordinates, or 120 for six. They preserve Hamming distance, parity, zero, and the normalized first unit word.

## Model and excluded-set invariance

The imported model retains the exact pair constraints reviewed in round 206, generalized to the requested block width. Its cache key includes base distance, consecutive status, and the current second-variable domain. Rows are calculated for every possible first word, so no missing first-domain parameter is needed. Intersections allocate new row lists; they do not mutate shared cached relations.

The normalized domain restrictions and the geometric binary relations are invariant under the supplied residual group. The forbidden set is also invariant in this particular generator. For either the forward or reversed source branch, the generator fixes the input histories used by the base coordinates and enumerates every bijective assignment of the remaining input coordinates to the block outputs. Composing an emitted witness with a residual block permutation leaves the fixed base assignment unchanged and gives another enumerated block assignment. Its first block word remains zero and its first transition word remains one. Thus the normalized witness remains in the list, up to tuple deduplication.

This closure argument applies even if choosing the first matching base column leaves other possible ambient isometries unenumerated: residual block permutations preserve the chosen base-column assignment. Every emitted forbidden tuple has an explicit full coordinate-permutation witness, possibly after reversing and translating the source. Removing the list is therefore safe, and its residual-group closure preserves orbit coverage of the model with those tuples excluded.

## Branching and limits

After propagation, each nonsingleton domain is eligible for branching. The minimum-domain/maximum-degree choice does not restrict coverage. The apparent access to `degree[chosen]` when `chosen` initially equals $-1$ is avoided by C short-circuit evaluation: every domain size is at most 64, while the initial best size is 65, so the first eligible candidate satisfies the earlier strict comparison.

The branch loop visits every retained value in the chosen domain. It returns immediately only for a witness or a limit. Return code two is propagated unchanged through all recursive callers; it cannot become an exhausted child. If all children return zero, the subtree is exhausted.

Time is checked at node entry. A propagation call can extend past the nominal deadline, but this does not produce false exhaustion: a normal exhausted return still means the traversal completed. The wrapper independently terminates a process exceeding its wall allowance and records `INTERRUPTED`. Resource stops and nonzero process exit codes are also recorded as interruptions, not exclusions.

All uses of the trailing-zero intrinsic receive a nonzero mask. Domain words and permutation values are bounded below 64; the full-width alphabet case avoids shifting by 64 when constructing the allowed mask. The fixed array bounds accommodate the wrapper's five- and six-coordinate models, subject to the reader's explicit dimension checks.

## Wrapper interpretation and remaining scope

The wrapper saves the generated model, permutation list, exact solver input, standard output, error output, and per-case record. For a returned solution it checks domain membership, every binary constraint, exclusion-list membership, every lex inequality, the reconstructed full path's inducedness, and preservation of all indexed base words. It also records source and executable hashes and checks that the pinned files are unchanged when producing the final report.

Those hashes identify files; they do not independently prove that the executable implements the reviewed C source. This review did not inspect a build receipt or execute the binary.

The outer `COMPLETE` status means every requested case was processed. It can include individual `LIMIT` results, so only case-level `EXHAUSTED` records justify native exclusions. A first witness terminates that case's search; `FOUND` does not enumerate all remaining solutions or classes. Canonical class comparison allows path reversal.

For the generated inputs, exhausted lex-restricted search covers every orbit of the original normalized model after the witnessed exclusions. Undoing normalization preserves the corresponding ambient cube class. This conclusion remains restricted to the fixed source, block partition, length, and index matching. The C search supplies no Lean certificate, and neither this review nor the abstract lexicographic draft discharges a concrete finite-search exclusion.
