# Independent review of the contracted search

For a set $S$ in one parity class, join two members when a vertex of the other parity has precisely those two neighbours in $S$. If $S$ is the majority class of an induced path, its traversal, taking every second vertex, gives a spanning path in this simple graph. Each intervening minority vertex witnesses its consecutive pair.

Suppose $k$ of the final majority vertices are still missing from a partial set. Delete their positions from the spanning path. The remaining vertices form at most $k+1$ nonempty runs. Each edge inside a run still has its original witness, since both of the witness's selected neighbours remain. Hence the partial contraction contains these runs as a spanning forest. Each isolated component of the forest contributes two missing incidences and each nontrivial component has two endpoints. Adding extra contraction edges can only reduce the sum of degree deficits below two. With $I$ isolated vertices and $L$ vertices of degree one, this proves $2I+L\le 2k+2$. It justifies the thresholds six after one deletion and four after one subsequent addition. At the final set of 97 vertices, a spanning path requires $I=0$ and $L\le2$. 

In `majority/screen.cpp`, each opposite vertex stores the mask of selected neighbours. Adding or removing one vertex changes nine masks. An edge starts or ends when the number of its witnessing masks crosses zero; this accounts for a pair with two witnesses. On insertion, the new vertex is first counted as isolated. On deletion, its nine updates return its degree to zero before it is removed from the isolated count. The outer loop tries every seed deletion and each unordered pair of distinct additions from the original 160-vertex complement.

The independent program `independent_screen.cpp` rebuilds degrees from immutable neighbourhood masks for each queried selection and performs no deletion pruning. It requires the four-unit deficit bound for *both* possible single-addition prefixes. To count a simple edge only once, it checks the other shared neighbour of the two endpoints. Among 177,062,400 descriptions, 430,488 pairs passed both prefix bounds. A fresh full contraction on each pair returned exactly the archived 679 descriptions, which specify 623 distinct labelled sets.

In `majority/finish.py`, adjoining one dummy vertex converts the spanning-path problem into a spanning-cycle problem. When there are two leaves, they must be the endpoints and the dummy can be restricted to them. Otherwise the dummy permits any vertex. A vertex on a Hamilton cycle needs exactly two incident cycle edges. This forces both edges at a vertex of remaining degree two and excludes any additional edges once two are forced. A proper cycle of forced edges is impossible. The remaining branch chooses an optional edge and considers both inclusion and exclusion.

`independent_check.py` reconstructed every surviving set from its seed and edits, computed simple edges by direct Hamming distances and solved each of the 623 directed circuit models independently. There is one node per majority vertex and an unrestricted dummy node. Each undirected edge gives both possible arcs. The lack of self-loops makes participation mandatory. The solver reported `INFEASIBLE` for every instance. This confirms the conclusions of the 623 decisions without depending on the branching order or selected leaf endpoints recorded by the first solver. The native finite enumeration and the circuit solver have no Lean contradiction replay here. Digests, per-base counts and per-graph solver outcomes are in `independent-results.json`.
