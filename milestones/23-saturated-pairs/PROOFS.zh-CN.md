# 位置分类与可手证的限制

所有本文件定理的证据等级均为「数学证明待形式化」。没有使用求解器的
INFEASIBLE 状态作为证明。S 是 Q9 中至少两个顶点的非空诱导路径的顶点集；
v=|S|，m=v−1。空面指四个顶点均不在 S 的坐标二维面。

## 1. 无重复表示和完整的位置分类

用 (a,b,q) 表示面，其中 0<=a<b<9，q 在 a,b 两位均为 0；顶点为
q、q xor 2^a、q xor 2^b、q xor 2^a xor 2^b。每个面恰有一个这种表示。
写 A={a,b}。外邻域 B(Q) 是七个互不相交的法向平移面 Q xor 2^k 的并，k 不在 A。
它有 28 个顶点。对空面，题目中的 |N(Q)∩S| 等于 |B(Q)∩S|。

对两个不同面定义 r=|A∩B|、d=min{dist(x,y):x∈Q,y∈R}。
允许的等价是全立方体平移 xor t、坐标置换以及交换两个面，均保持真实蛇。

**完备性证明。** 首先把 Q 变为 (0,1,0)。保持 Q 的坐标置换可把 R 的
自由坐标变为 r=0 时 {2,3}、r=1 时 {0,2}、r=2 时 {0,1}。
沿 Q 自由坐标的平移保持 Q，并可消去 R 在 A\B 上的固定比特。
两面不共享的自由坐标上的距离都能通过选角消去。因此唯一剩下的固定差异，
是 A∪B 外的 5+r 个坐标上的一个比特向量；它的重量正好是 d。
置换这些坐标把非零位移到最前 d 位，得到规范代表。反过来 r,d 显然不随
这些操作改变。因此它们是完整不变量；交换两面也不合并不同 (r,d)。

范围为 r=0,d=0..5；r=1,d=0..6；r=2,d=1..7，共 20 类。
r=2,d=0 是同一个面，排除。固定 Q 时，每类面 R 的个数为

    C(2,r) C(7,2−r) 2^(2−r) C(5+r,d).

分类程序独立遍历全部 4607 个 R 检查该公式。规范代表、共享顶点、共享外邻域、
对方落入自己外邻域的顶点完整保存于 runs/inventory-a/classes.json。
两面相交当且仅当 d=0，交集有 2^r 个顶点；d=1 表示相邻。

这只是**位置分类**，没有声称把带遗漏角标记的配置也归为 20 类。
求解器对遗漏角的所有选择使用共同的布尔变量，不固定或分别选择两个见证。
面 (a,b,q) 中角点 u 的局部奇偶定义为 u 在 a,b 位的比特和模 2。
法向层 k 的遗漏顶点先 xor 2^k 平移回面内，再按此定义计算。
不同面的「0/1 奇偶」不被当作同一全局标签；只使用各面自身是否混合这一不变量。

## 2. 饱和的基本后果

任何坐标二维面至多有三个选中点，否则 S 的诱导图含四圈。
因此 b(Q)<=7·3=21。达到 21 当且仅当七个法向平移面各选三个点；
每层为一个 P3，遗漏角唯一，中心的两个路径邻点已在该层中。

## 3. 五类排斥

### P1D0、P1D1 和 P2D1：直接的空性冲突

P1D0 可取 Q=(0,1,0), R=(0,2,0)。空的 R 使 Q 的法向层 k=2
至少缺少 4、5 两点，该层至多选两个，因此 b(Q)<=20；交换 Q,R 同理。
P1D1 可取 R=(0,2,8)。Q 的层 k=3 缺少 8、9，同样 b(Q),b(R)<=20。
P2D1 中 R 就是 Q 的一个法向平移层，整层为空，所以 b(Q),b(R)<=18。
这些命题只假设两面为空，不要求另一面饱和。

### P0D0：强迫一个八圈

取 Q=(0,1,0), R=(2,3,0)。若两面均空且饱和：
Q 的第 2、3 法向层分别被迫选 {5,6,7}、{9,10,11}；
R 的第 0、1 法向层分别被迫选 {5,9,13}、{6,10,14}。
于是所有以下顶点均选中，连续项及首尾相邻：

    5—7—6—14—10—11—9—13—5.

路径的任意子图都不含圈，矛盾。因此两个这样的空面不能同时饱和；
利用整数性和各自上限 21，还得到 b(Q)+b(R)<=41。
局部模型只含四圈，确实允许这类配置；这里新增的是可见的八圈条件。

### P2D3：更强的 b(Q)+b(R)<=39

令 Q 的自由坐标为 a,b，R=Q xor 2^c xor 2^d xor 2^e，
其中 c,d,e 是三个不同法向坐标。考虑由下列六个平行面组成的 24 点集合 U：

    Q^c, Q^d, Q^e, Q^{c,d}, Q^{c,e}, Q^{d,e}.

法向三立方体去掉 000、111 后为 C6，故 Q9 在 U 上的诱导图是 C4 □ C6，
4 正则，24 个顶点、48 条边。设 p=|U∩S|。删除 24−p 个顶点至多删除
4(24−p) 条边，因而选中诱导子图至少有 4p−48 条边。
若 p>=1，该子图是森林，至多有 p−1 条边，因此 3p<=47，p<=15；p=0 也满足。

两个面的外邻域不重叠。它们各有三个法向层在 U 中，剩下共八个平行四圈，
每个至多选三点。因此 b(Q)+b(R)<=15+8·3=39。
特别地，若 b(Q)=21 且 R 为空，则 b(R)<=18。
这不是只排除「21 与 21」：总亏损至少为 3。

同一推导在 Qn、n>=5 中给出 b(Q)+b(R)<=15+6(n−5)=6n−15；
相对于两份 3(n−2) 的容量，总亏损仍至少为 3。系数由实际层数重新推导。
不声称常数 39 尖锐；固定 b(Q)=21、b(R)=18 的全局搜索限时未解决。

## 4. 饱和面数量的全局界

令 M 是饱和空面数。不同饱和面**两两顶点不交**：相交的不同二维面只有
P0D0 和 P1D0 两种位置，已被上面的证明排除。所以

    4M <= 512−v.

对一个选中顶点 x 和一个它触及的空面 Q，x 恰与 Q 的一个角相邻：
x 必须在一个法向平移层中，只有平移回去的角与它距离一。
不同饱和面的角点又不重合，故所有 21M 个触及关联注入 S 到其补集的割边。
蛇内有 v−1 条边，割边总数为 9v−2(v−1)=7v+2。因此

    21M <= 7v+2,   M <= floor(v/3).

综合得

    M <= min(s0, floor(v/3), floor((512−v)/4)) <= 73.

最后一步由 v>=3M 与 512−v>=4M 相加得 7M<=512。
这给出严格的全局数量限制，但它不自动给出新的边数上界。

## 5. 从排斥到亏损：完整分摊

记 δ(Q)=21−b(Q)>=0，D=Σ空面 δ(Q)=21s0−H。
所有非饱和面至少亏损 1，故

    D >= s0−M,    H <= 20s0+M.

令 G3 的顶点为实际空面，同自由坐标、距离 3 时连边；e3=|E(G3)|。
每条边 {Q,R} 有 δ(Q)+δ(R)>=3。每个面至多有 C(7,3)=35 个这种邻面。
逐边求和给出

    3e3 <= Σ空面 deg_G3(Q) δ(Q) <= 35D,
    D >= ceil(3e3/35).

这明确控制同一亏损面的重复使用次数，不假设空面周围必然还有空面。
若只对饱和面向距离 3 的空面配对计数，令 K3 为这类有向关联数。
每个饱和面向每个这样的邻面分出 3 单位；接收者 δ>=3，最多收到 35·3 单位，
因此其收款不超过 35δ。仍得到 D>=ceil(3K3/35)。饱和面之间没有 G3 边，
所以 K3<=e3；使用全部 e3 的版本至少同样强。

另令 e00 为 P0D0 空面无序对数，则逐边亏损至少 1、每面至多有 84 个邻面，
所以 D>=ceil(e00/84)。这些 D 下界一般**不能相加**，同一亏损可以同时支付
不同类型的关联。本报告只取它们的最大值，不重复计算收益。

端点只在割边总数 7v+2 中出现；森林、四圈和空性推导都允许端点，不另作
内部顶点假设。所有计数都针对实际完整的四顶点坐标面，而非未检查的局部空缺。
